title: "Migrating from kaspad to rusty-kaspa"
description: "Migration guide from the legacy Go-based kaspad node to rusty-kaspa: key differences, data directory changes, CLI flag mapping, RPC compatibility, and performance improvements."
---

The original Kaspa node (`kaspad`) was written in Go. It has been replaced by **rusty-kaspa**, a ground-up Rust rewrite that is now the reference implementation.

<Callout type="warn">
The Go-based kaspad is deprecated and no longer receives updates. All operators should migrate to rusty-kaspa. The Go node does not support 10 BPS and cannot remain on the network after the Crescendo hardfork.
</Callout>

## Why Migrate

| Aspect | Go kaspad | rusty-kaspa |
|---|---|---|
| Block rate | 1 BPS only | 10 BPS (Crescendo) |
| Memory usage | Higher at equivalent workloads | Lower at equivalent workloads (environment-dependent) |
| Sync speed | Slower on current network history | Faster on comparable hardware (environment-dependent) |
| RPC protocol | gRPC only | wRPC (WebSocket) + gRPC |
| WASM SDK | Not available | Full SDK for browsers and Node.js |
| Development | Stopped | Active |

## Installation

```bash
git clone https://github.com/kaspanet/rusty-kaspa.git
cd rusty-kaspa
cargo build --release --bin kaspad --bin kaspa-wallet
```

Pre-built binaries are available on the [rusty-kaspa releases page](https://github.com/kaspanet/rusty-kaspa/releases).

## Data Directory Migration

The database formats are incompatible. **A fresh sync is required.**

| Item | Go kaspad | rusty-kaspa |
|---|---|---|
| Default data dir | `~/.kaspad/` | `~/.rusty-kaspa/` |
| Database engine | LevelDB | RocksDB |

<Callout type="info">
Run both nodes in parallel during migration: start rusty-kaspa on alternate ports (`--rpclisten=0.0.0.0:17110 --listen=0.0.0.0:17111`) while the Go node serves traffic. Switch over after sync completes.
</Callout>

## CLI Flag Changes

| Purpose | Go kaspad | rusty-kaspa |
|---|---|---|
| UTXO index | `--utxoindex` | `--utxoindex` |
| RPC listen | `--rpclisten` | `--rpclisten` |
| P2P listen | `--listen` | `--listen` |
| Testnet / Simnet | `--testnet` / `--simnet` | `--testnet` / `--simnet` |
| Data directory | `--appdir` | `--appdir` |
| No log files | N/A | `--nologfiles` |
| RAM scaling | N/A | `--ram-scale` |
| Perf metrics | N/A | `--perf-metrics` |

## RPC Compatibility

| Feature | Go kaspad | rusty-kaspa |
|---|---|---|
| Transport | gRPC (HTTP/2) | wRPC (WebSocket) + gRPC |
| Encoding | Protobuf | Borsh (binary) or JSON |
| Default gRPC port | 16110 | 16110 |
| Default wRPC port | N/A | 17110 (Borsh) / 18110 (JSON) |

Migrate to the WASM SDK for the best experience:

```typescript
// Old: gRPC client (Go ecosystem)
// const client = new KaspadClient("localhost:16110");

// New: wRPC client (WASM SDK)
import { RpcClient, Encoding } from "kaspa-wasm";
const rpc = new RpcClient({ url: "ws://127.0.0.1:17110", encoding: Encoding.Borsh });
await rpc.connect();
const dagInfo = await rpc.getBlockDagInfo();
```

### RPC Method Mapping

| Go kaspad RPC | WASM SDK method |
|---|---|
| `GetBlockDAGInfo` | `rpc.getBlockDagInfo()` |
| `GetBlock` | `rpc.getBlock()` |
| `SubmitTransaction` | `rpc.submitTransaction()` |
| `GetUTXOsByAddresses` | `rpc.getUtxosByAddresses()` |
| `GetBalanceByAddress` | `rpc.getBalanceByAddress()` |
| `GetInfo` | `rpc.getInfo()` |

<Callout type="info">
rusty-kaspa supports WebSocket subscriptions (`subscribeUtxosChanged`, `subscribeBlockAdded`, etc.) replacing the gRPC streaming pattern.
</Callout>

## Post-Migration Checklist

- Verify `getInfo().isSynced` returns `true`
- Confirm peer count is healthy (10+ peers)
- Update monitoring scripts to use the new RPC client
- Update firewall rules if ports changed
- Remove old Go kaspad data directory (`~/.kaspad/`)
- Update systemd service files to point to the new binary
