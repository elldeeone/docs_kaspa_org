---
title: "Setting Up a Development Environment"
description: "Install Rust, build rusty-kaspa from source, launch a local simnet, install the WASM SDK, and configure your IDE for Kaspa development."
---

A productive Kaspa development environment lets you build, test, and iterate locally before deploying against testnet or mainnet. This guide covers the full setup: Rust toolchain, rusty-kaspa compilation, a local simnet for instant testing, the WASM SDK for application code, and IDE configuration.

## Prerequisites

| Requirement | Version |
|---|---|
| Operating system | Linux, macOS, or WSL2 on Windows |
| Git | 2.x+ |
| Node.js (for WASM SDK) | 18+ |
| Disk space | 10 GB free (build artifacts) |

## Step 1 -- Install the Rust Toolchain

Install Rust via `rustup`, the official installer:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustup default stable
rustup target add wasm32-unknown-unknown
```

The `wasm32-unknown-unknown` target is needed if you plan to compile the WASM SDK from source. Verify the install:

```bash
rustc --version   # e.g. rustc 1.78.0
cargo --version
```

## Step 2 -- Clone and Build rusty-kaspa

```bash
git clone https://github.com/kaspanet/rusty-kaspa.git
cd rusty-kaspa
cargo build --release --bin kaspad --bin kaspa-wallet
```

<Callout type="info">
A release build takes 5-15 minutes depending on hardware. The binaries land in `target/release/`. You can add this directory to your `PATH` for convenience.
</Callout>

The key binaries:

| Binary | Purpose |
|---|---|
| `kaspad` | Full node daemon |
| `kaspa-wallet` | Interactive CLI wallet |
| `rothschild` | Transaction load generator (testing) |

## Step 3 -- Launch a Local Simnet

Simnet is a private, single-node network ideal for development. No external peers, instant mining, and full control.

```bash
kaspad --simnet --utxoindex --rpclisten=0.0.0.0:16510
```

In a second terminal, connect the wallet:

```bash
kaspa-wallet
wallet> connect 127.0.0.1:16510
wallet> create
wallet> address
```

<Callout type="warn">
Simnet resets every time you clear its data directory. This is useful for clean-state testing but means you must re-fund wallets after a restart.
</Callout>

Simnet uses port **16510** for wRPC. See [Simnet](/docs/node-operations/simnet) for full details.

## Step 4 -- Install the WASM SDK

For application-level development in TypeScript or JavaScript:

```bash
mkdir my-kaspa-app && cd my-kaspa-app
npm init -y
npm install kaspa-wasm typescript tsx
```

Create a quick connectivity test (`test-connect.ts`):

```typescript
import { RpcClient, Encoding } from "kaspa-wasm";

async function main() {
  const rpc = new RpcClient({
    url: "ws://127.0.0.1:16510",
    encoding: Encoding.Borsh,
  });
  await rpc.connect();

  const info = await rpc.getInfo();
  console.log("Network:", info.networkId);
  console.log("Synced:", info.isSynced);

  await rpc.disconnect();
}

main().catch(console.error);
```

```bash
npx tsx test-connect.ts
```

If it prints the network and sync status, your SDK and local node are wired up correctly.

## Step 5 -- Configure Your IDE

For **VS Code**, install **rust-analyzer** (Rust language server), **CodeLLDB** (debugger), and **ESLint** + **Prettier** (TypeScript). Set `"rust-analyzer.check.command": "clippy"` in workspace settings for inline linting. For **JetBrains** IDEs, install the Rust plugin and open rusty-kaspa as a Cargo project.

## Development Workflow

1. **Start simnet** -- Launch `kaspad --simnet --utxoindex` in a dedicated terminal.
2. **Fund a wallet** -- Use the CLI wallet to mine or transfer simnet KAS.
3. **Write SDK code** -- Build your application logic against the local node.
4. **Test on testnet** -- Once stable, point your app at testnet-10 or testnet-11 (see [Testnet Development](/docs/guides/testnet-development)).
5. **Deploy to mainnet** -- Switch `networkId` to `"mainnet"` and connect via port 16110.
