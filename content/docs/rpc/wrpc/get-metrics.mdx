---
title: "GetMetrics"
description: "Get comprehensive performance and resource metrics from the node."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `processMetrics` | boolean | No | Whether to include process metrics (CPU, memory, etc.). |
| `connectionMetrics` | boolean | No | Whether to include connection metrics. |
| `bandwidthMetrics` | boolean | No | Whether to include bandwidth metrics. |
| `consensusMetrics` | boolean | No | Whether to include consensus metrics. |
| `storageMetrics` | boolean | No | Whether to include storage metrics. |
| `customMetrics` | boolean | No | Whether to include custom metrics. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `serverTime` | u64 | The current server time in milliseconds since epoch. |
| `processMetrics` | object \| null | Returned when `processMetrics=true`. Fields: `residentSetSize`, `virtualMemorySize`, `coreNum`, `cpuUsage`, `fdNum`, `diskIoReadBytes`, `diskIoWriteBytes`, `diskIoReadPerSec`, `diskIoWritePerSec`. |
| `connectionMetrics` | object \| null | Returned when `connectionMetrics=true`. Fields: `borshLiveConnections`, `borshConnectionAttempts`, `borshHandshakeFailures`, `jsonLiveConnections`, `jsonConnectionAttempts`, `jsonHandshakeFailures`, `activePeers`. |
| `bandwidthMetrics` | object \| null | Returned when `bandwidthMetrics=true`. Fields: `borshBytesTx`, `borshBytesRx`, `jsonBytesTx`, `jsonBytesRx`, `p2pBytesTx`, `p2pBytesRx`, `grpcBytesTx`, `grpcBytesRx`. |
| `consensusMetrics` | object \| null | Returned when `consensusMetrics=true`. Fields: `nodeBlocksSubmittedCount`, `nodeHeadersProcessedCount`, `nodeDependenciesProcessedCount`, `nodeBodiesProcessedCount`, `nodeTransactionsProcessedCount`, `nodeChainBlocksProcessedCount`, `nodeMassProcessedCount`, `nodeDatabaseBlocksCount`, `nodeDatabaseHeadersCount`, `networkMempoolSize`, `networkTipHashesCount`, `networkDifficulty`, `networkPastMedianTime`, `networkVirtualParentHashesCount`, `networkVirtualDaaScore`. |
| `storageMetrics` | object \| null | Returned when `storageMetrics=true`. Field: `storageSizeBytes`. |
| `customMetrics` | object \| null | Returned when `customMetrics=true`; currently reserved/placeholder. |

## Notes

- Metrics provide a comprehensive snapshot of the node's health and resource consumption.
- Use this for building monitoring dashboards, alerting systems, or capacity planning.
- Each metrics sub-object is conditional on the corresponding request flag.
- This is a heavier call than `GetInfo` or `GetConnections`; avoid polling at very high frequencies.
