---
title: "GetSyncStatus"
description: "Check whether the node is fully synchronized with the Kaspa network."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `isSynced` | boolean | `true` if the node is fully synced with the network, `false` otherwise. |

## Example

```json
// Request
{
  "method": "getSyncStatus",
  "params": {}
}

// Response
{
  "isSynced": true
}
```

## Notes

- A node is considered synced when it has downloaded and validated all blocks up to the current network tip.
- During initial block download (IBD), this returns `false`. IBD can take minutes to hours depending on the network and hardware.
- Applications should check sync status before trusting balance or UTXO data from the node.
- This is the simplest way to check if a node is ready to serve accurate data.
