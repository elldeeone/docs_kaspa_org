---
title: "GetConnections"
description: "Get the number of active peer and client connections to the node."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `includeProfileData` | boolean | No | Whether to include connection profile data in the response. Defaults to `false` when omitted. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `clients` | u32 | Number of currently connected wRPC clients (JSON + Borsh transports). |
| `peers` | u16 | Number of P2P peers currently connected. |
| `profileData` | object \| null | Connection profile data (`cpuUsage`, `memoryUsage`), present when `includeProfileData=true`. |

## Example

```json
// Request
{
  "method": "getConnections",
  "params": {
    "includeProfileData": true
  }
}

// Response
{
  "clients": 3,
  "peers": 48,
  "profileData": {
    "cpuUsage": 8.4,
    "memoryUsage": 734003200
  }
}
```

## Notes

- `peers` reflects P2P connections to other Kaspa nodes for block and transaction propagation.
- `clients` currently reflects active wRPC client connections.
- Use this for monitoring node health and connectivity.
