---
title: "GetFeeEstimate"
description: "Get current fee rate estimates for transaction prioritization."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `estimate` | object | The fee estimate object containing priority buckets. |
| `estimate.priorityBucket` | object | Fee rate for high-priority (next block) inclusion. |
| `estimate.priorityBucket.feerate` | number | Recommended fee rate in sompi per gram of mass. |
| `estimate.priorityBucket.estimatedSeconds` | number | Estimated time to confirmation at this fee rate. |
| `estimate.normalBuckets` | object[] | Fee rate buckets for normal-priority transactions. |
| `estimate.lowBuckets` | object[] | Fee rate buckets for low-priority (economy) transactions. |

Each bucket contains `feerate` (number) and `estimatedSeconds` (number).

## Example

```json
// Request
{
  "method": "getFeeEstimate",
  "params": {}
}

// Response
{
  "estimate": {
    "priorityBucket": {
      "feerate": 10.0,
      "estimatedSeconds": 1.0
    },
    "normalBuckets": [
      { "feerate": 5.0, "estimatedSeconds": 5.0 },
      { "feerate": 2.0, "estimatedSeconds": 15.0 }
    ],
    "lowBuckets": [
      { "feerate": 1.0, "estimatedSeconds": 60.0 }
    ]
  }
}
```

## Notes

<Callout type="info">
Fee estimates are based on current mempool conditions and recent block data. During periods of high network activity, fee rates will be higher. During low activity, even the minimum fee rate is sufficient.
</Callout>

- Use the `priorityBucket` fee rate for time-sensitive transactions that need to be confirmed as quickly as possible.
- The `normalBuckets` provide a range of fee/time trade-offs for typical transactions.
- Fee rates are expressed in sompi per gram of transaction mass.
- Under normal network conditions, Kaspa fees are extremely low. Fee estimation becomes important primarily during congestion.
