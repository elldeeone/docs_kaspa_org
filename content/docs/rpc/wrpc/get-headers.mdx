---
title: "GetHeaders"
description: "Retrieve a range of block headers starting from a given hash (currently unimplemented)."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `startHash` | string | Yes | The hash of the block to start from. |
| `limit` | u64 | Yes | Maximum number of headers to return. |
| `isAscending` | boolean | Yes | If `true`, returns headers in ascending order (oldest first). If `false`, descending (newest first). |

## Response

Current node behavior: this method returns a `NotImplemented` error.

## Example

```json
// Request
{
  "method": "getHeaders",
  "params": {
    "startHash": "6ef1913d30d5063e040839fcc67cbf02e8e0ae6e4a3cb774c7777043399697f5",
    "limit": 100,
    "isAscending": true
  }
}

// Response
{
  "error": {
    "message": "Not implemented"
  }
}
```

## Notes

- The request schema (`startHash`, `limit`, `isAscending`) is part of the RPC API surface, but the server currently does not implement this call.
- Do not rely on this method for production flows until implementation is available.
