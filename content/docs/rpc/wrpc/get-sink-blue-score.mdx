---
title: "GetSinkBlueScore"
description: "Get the blue score of the current sink block."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `blueScore` | u64 | The blue score of the current sink block. |

## Example

```json
// Request
{
  "method": "getSinkBlueScore",
  "params": {}
}

// Response
{
  "blueScore": 48000000
}
```

## Notes

- The returned value is the GHOSTDAG blue score of the current sink (virtual selected parent).
- Blue score increases monotonically and can be used as a rough measure of chain progress.
- Blue score growth rate is network- and conditions-dependent.
- This is a lightweight call suitable for frequent polling.
