---
title: "SubmitTransactionReplacement"
description: "Submit a transaction that replaces an existing transaction in the mempool (Replace-by-Fee)."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `transaction` | object | Yes | The signed replacement transaction object. Must spend at least one of the same inputs as the transaction being replaced, and must pay a higher fee. |

The `transaction` object follows the same structure as in `SubmitTransaction`.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `transactionId` | string | The hash/ID of the new replacement transaction. |
| `replacedTransaction` | object | The transaction that was replaced in the mempool. |

## Example

```json
// Request
{
  "method": "submitTransactionReplacement",
  "params": {
    "transaction": {
      "version": 0,
      "inputs": [
        {
          "previousOutpoint": {
            "transactionId": "aabb1122...",
            "index": 0
          },
          "signatureScript": "41...",
          "sequence": 0,
          "sigOpCount": 1
        }
      ],
      "outputs": [
        {
          "value": 99000000,
          "scriptPublicKey": { "version": 0, "script": "20..." }
        }
      ],
      "lockTime": 0,
      "subnetworkId": "0000000000000000000000000000000000000000"
    }
  }
}

// Response
{
  "transactionId": "eeff7788...",
  "replacedTransaction": {
    "inputs": [{ "previousOutpoint": { "transactionId": "aabb1122...", "index": 0 } }],
    "outputs": [{ "value": 99500000, "scriptPublicKey": { "version": 0, "script": "20..." } }]
  }
}
```

## Notes

<Callout type="info">
The replacement transaction must pay a higher fee than the transaction it replaces. This is Kaspa's Replace-by-Fee (RBF) mechanism, allowing users to bump the priority of stuck transactions.
</Callout>

- The replacement must spend at least one input in common with the transaction being replaced.
- The replaced transaction is evicted from the mempool and returned in the response.
- If no matching transaction is found in the mempool, the method returns an error.
