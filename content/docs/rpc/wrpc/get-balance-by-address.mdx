---
title: "GetBalanceByAddress"
description: "Get the total balance of a single Kaspa address."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `address` | string | Yes | The Kaspa address to query the balance for. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `balance` | u64 | The total balance in sompi (1 KAS = 100,000,000 sompi). |

## Example

```json
// Request
{
  "method": "getBalanceByAddress",
  "params": {
    "address": "kaspa:qr0l4g5untavmz2mn5yd4e6qpsh7tg2hfqlfsle8xhncpgy5qxuq9kdarzy4"
  }
}

// Response
{
  "balance": 1500000000
}
```

## Notes

<Callout>
This method requires the node to have the UTXO index enabled (`--utxoindex` flag).
</Callout>

- The balance is the sum of all unspent transaction outputs (UTXOs) for the address.
- The returned value is in **sompi**. Divide by 100,000,000 to get KAS.
- This balance does not include unconfirmed (mempool) transactions. For pending transactions, use `GetMempoolEntriesByAddresses`.
- For querying multiple addresses at once, use `GetBalancesByAddresses`.
