---
title: "GetBalancesByAddresses"
description: "Get the total balance for multiple Kaspa addresses in a single call."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `addresses` | string[] | Yes | List of Kaspa addresses to query balances for. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `entries` | object[] | Array of address-balance pairs. |
| `entries[].address` | string | The queried address. |
| `entries[].balance` | u64 | The total balance in sompi. |

## Example

```json
// Request
{
  "method": "getBalancesByAddresses",
  "params": {
    "addresses": [
      "kaspa:qr0l4g5untavmz2mn5yd4e6qpsh7tg2hfqlfsle8xhncpgy5qxuq9kdarzy4",
      "kaspa:qqe8ranlpwnhfy9lfxvragz32grsv7n2c8lsqjg5tf7hcfqzk8djsdy8lyum"
    ]
  }
}

// Response
{
  "entries": [
    {
      "address": "kaspa:qr0l4g5untavmz2mn5yd4e6qpsh7tg2hfqlfsle8xhncpgy5qxuq9kdarzy4",
      "balance": 1500000000
    },
    {
      "address": "kaspa:qqe8ranlpwnhfy9lfxvragz32grsv7n2c8lsqjg5tf7hcfqzk8djsdy8lyum",
      "balance": 250000000
    }
  ]
}
```

## Notes

<Callout>
This method requires the node to have the UTXO index enabled (`--utxoindex` flag).
</Callout>

- Balances are in **sompi** (1 KAS = 100,000,000 sompi).
- This is more efficient than calling `GetBalanceByAddress` repeatedly for multiple addresses.
- Addresses with no UTXOs return a balance of `0`.
