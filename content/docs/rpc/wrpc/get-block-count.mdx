---
title: "GetBlockCount"
description: "Get estimated counts of blocks and headers in the node database."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `headerCount` | u64 | Estimated number of stored headers. |
| `blockCount` | u64 | Estimated number of stored full blocks (with body data). |

## Example

```json
// Request
{
  "method": "getBlockCount",
  "params": {}
}

// Response
{
  "headerCount": 52340000,
  "blockCount": 52340000
}
```

## Notes

- These values are DAA-score-based estimates, not exact totals.
- Estimates exclude some data classes (for example non-DAA blocks and pruning-proof-only headers).
- `headerCount` may be greater than `blockCount` during initial block download (IBD), when the node has received headers but has not yet downloaded all block bodies.
- This method is useful for monitoring sync progress.
