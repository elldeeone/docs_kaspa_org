---
title: "GetPeerAddresses"
description: "Get the list of known and banned peer addresses from the node's address book."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `knownAddresses` | object[] | List of known peer network addresses (`ip`, `port`). |
| `bannedAddresses` | string[] | List of banned IP addresses. |

## Example

```json
// Request
{
  "method": "getPeerAddresses",
  "params": {}
}

// Response
{
  "knownAddresses": [
    { "ip": "192.168.1.100", "port": 16111 },
    { "ip": "10.0.0.50", "port": 16111 }
  ],
  "bannedAddresses": [
    "203.0.113.50"
  ]
}
```

## Notes

- Known addresses are addresses currently stored in the node's address manager (source and scoring policy are implementation details).
- Not all known addresses are currently connected; they are potential peers the node may connect to.
- Banned addresses are IPs currently present in the node's ban list.
