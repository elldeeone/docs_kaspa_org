---
title: "GetBlocks"
description: "Retrieve a batch of blocks starting from a given hash, useful for syncing or scanning the DAG."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `lowHash` | string | No | The hash to start from. If provided, it is included as the first returned hash. If omitted, starts from the genesis block. |
| `includeBlocks` | boolean | Yes | Whether to include full block data. |
| `includeTransactions` | boolean | Yes | Whether to include transactions within blocks. Only relevant if `includeBlocks` is `true`. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `blockHashes` | string[] | Ordered list of block hashes from `lowHash` onward. |
| `blocks` | object[] | Always present. Contains block objects when `includeBlocks=true`, otherwise an empty array. |

## Example

```json
// Request
{
  "method": "getBlocks",
  "params": {
    "lowHash": "6ef1913d30d5063e040839fcc67cbf02e8e0ae6e4a3cb774c7777043399697f5",
    "includeBlocks": true,
    "includeTransactions": false
  }
}

// Response
{
  "blockHashes": [
    "aabb1122...",
    "ccdd3344..."
  ],
  "blocks": [
    {
      "header": { "version": 1, "daaScore": 50000001 },
      "verboseData": { "hash": "aabb1122...", "blueScore": 48000001 }
    }
  ]
}
```

## Notes

- The node returns blocks in topological order from the low hash.
- The number of blocks returned per call is bounded by the node's internal limits.
- `lowHash` is inclusive. If you paginate by reusing the previous page's last hash, skip the first returned hash on the next page to avoid duplicates.
- If `lowHash` refers to a pruned block, the node returns an error.
