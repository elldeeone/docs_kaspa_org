---
title: "GetSystemInfo"
description: "Get system-level information about the node's host machine and build."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | The node software version. |
| `systemId` | string | A unique identifier for the system/node instance. |
| `gitHash` | string | The git commit hash of the node build. |
| `coreNum` | u32 | Number of CPU cores available to the node. |
| `totalMemory` | u64 | Total system memory in bytes. |
| `fdLimit` | u32 | The file descriptor limit for the process. |

## Example

```json
// Request
{
  "method": "getSystemInfo",
  "params": {}
}

// Response
{
  "version": "0.15.0",
  "systemId": "node-abc123",
  "gitHash": "a1b2c3d4e5f6",
  "coreNum": 8,
  "totalMemory": 17179869184,
  "fdLimit": 65536
}
```

## Notes

- This method is primarily useful for diagnostics and monitoring dashboards.
- The `gitHash` helps identify the exact build of the node software when reporting issues.
- A low `fdLimit` can cause connection issues on nodes with many peers; the recommended minimum is 4096.
