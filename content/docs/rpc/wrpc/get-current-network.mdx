---
title: "GetCurrentNetwork"
description: "Get the name of the network the node is connected to."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `network` | string | The network type (`mainnet`, `testnet`, `simnet`, or `devnet`). |

## Example

```json
// Request
{
  "method": "getCurrentNetwork",
  "params": {}
}

// Response (mainnet)
{
  "network": "mainnet"
}

// Response (testnet)
{
  "network": "testnet"
}
```

## Notes

- The `network` field here is a network type, not a suffixed network ID.
- If you need the suffixed identifier (for example `testnet-10`), use `GetServerInfo.networkId`.
- Use this to verify your application is connected to the expected network before performing operations.
