---
title: "GetCurrentNetwork"
description: "Get the name of the network the node is connected to."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `network` | string | The network name (e.g., `mainnet`, `testnet-10`, `testnet-11`). |

## Example

```json
// Request
{
  "method": "getCurrentNetwork",
  "params": {}
}

// Response (mainnet)
{
  "network": "mainnet"
}

// Response (testnet)
{
  "network": "testnet-10"
}
```

## Notes

- The `network` field returns the network identifier (e.g., `mainnet`, `testnet-10`).
- Use this to verify your application is connected to the expected network before performing operations.
