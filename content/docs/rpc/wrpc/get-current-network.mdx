---
title: "GetCurrentNetwork"
description: "Get the name of the network the node is connected to."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `networkName` | string | The base network name (e.g., `kaspa`). |
| `suffix` | string or null | The network suffix (e.g., `testnet-10`, `testnet-11`, `simnet`). `null` for mainnet. |

## Example

```json
// Request
{
  "method": "getCurrentNetwork",
  "params": {}
}

// Response (mainnet)
{
  "networkName": "kaspa",
  "suffix": null
}

// Response (testnet)
{
  "networkName": "kaspa",
  "suffix": "testnet-10"
}
```

## Notes

- The full network identifier is formed by combining the name and suffix: `kaspa-mainnet`, `kaspa-testnet-10`, etc.
- Use this to verify your application is connected to the expected network before performing operations.
- Mainnet has a `null` suffix; all test networks have a non-null suffix.
