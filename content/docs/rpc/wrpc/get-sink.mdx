---
title: "GetSink"
description: "Get the hash of the current sink block (the tip of the selected parent chain)."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `sink` | string | The hash of the current sink block. |

## Example

```json
// Request
{
  "method": "getSink",
  "params": {}
}

// Response
{
  "sink": "6ef1913d30d5063e040839fcc67cbf02e8e0ae6e4a3cb774c7777043399697f5"
}
```

## Notes

- The sink is the tip of the virtual's selected parent chain. It represents the most recent block on the "main" chain as determined by GHOSTDAG.
- The sink changes frequently at 10 BPS. Do not cache this value for extended periods.
- The sink is sometimes referred to as the "virtual selected parent" in older documentation.
