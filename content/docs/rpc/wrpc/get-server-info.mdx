---
title: "GetServerInfo"
description: "Get detailed server information including RPC API version and network details."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `rpcApiVersion` | u16 | The RPC API version number. |
| `rpcApiRevision` | u16 | The RPC API revision number. |
| `serverVersion` | string | The node software version string. |
| `networkId` | string | The network identifier (e.g., `mainnet`, `testnet-10`). |
| `hasUtxoIndex` | boolean | Whether the UTXO index is enabled. |
| `isSynced` | boolean | Whether the node is fully synced. |
| `virtualDaaScore` | u64 | The current virtual DAA score. |

## Example

```json
// Request
{
  "method": "getServerInfo",
  "params": {}
}

// Response
{
  "rpcApiVersion": 1,
  "rpcApiRevision": 0,
  "serverVersion": "0.15.0",
  "networkId": "mainnet",
  "hasUtxoIndex": true,
  "isSynced": true,
  "virtualDaaScore": 50000000
}
```

## Notes

- Use `rpcApiVersion` and `rpcApiRevision` to check compatibility between your client and the node. Breaking changes increment the version number.
- `networkId` is serialized without a `kaspa-` prefix.
- `virtualDaaScore` provides the same value as `GetBlockDagInfo` but with a simpler call.
