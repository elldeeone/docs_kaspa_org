---
title: "Ban"
description: "Ban a peer by IP address, disconnecting it and preventing future connections."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `ip` | string | Yes | The IP address to ban (without port). |

## Response

Empty response on success.

## Example

```json
// Request
{
  "method": "ban",
  "params": {
    "ip": "203.0.113.50"
  }
}

// Response
{}
```

## Notes

- Banning an IP immediately disconnects any peer with that address and prevents future connections from it.
- Bans expire automatically after the node's max ban time (currently 24 hours), or can be removed earlier with `Unban`.
- Use `GetPeerAddresses` to view the current list of banned IPs.
- This is an administrative operation. Restrict RPC access to prevent unauthorized banning.
