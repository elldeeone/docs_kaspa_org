---
title: "SubmitTransaction"
description: "Submit a signed transaction to the node's mempool for propagation and inclusion in a block."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `transaction` | object | Yes | The signed transaction object containing inputs, outputs, and subnetworkId. |
| `allowOrphan` | boolean | No | Whether to allow the transaction to be accepted as an orphan (missing parent transactions). Defaults to `false`. |

The `transaction` object must include:
- `version` (u16): Transaction version.
- `inputs` (array): Each input has `previousOutpoint` (transactionId, index), `signatureScript`, `sequence`, and `sigOpCount`.
- `outputs` (array): Each output has `value` (u64, in sompi) and `scriptPublicKey`.
- `lockTime` (u64): Lock time for the transaction.
- `subnetworkId` (string): The subnetwork identifier.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `transactionId` | string | The hash/ID of the submitted transaction. |

## Example

```json
// Request
{
  "method": "submitTransaction",
  "params": {
    "transaction": {
      "version": 0,
      "inputs": [
        {
          "previousOutpoint": {
            "transactionId": "aabb1122...",
            "index": 0
          },
          "signatureScript": "41...",
          "sequence": 0,
          "sigOpCount": 1
        }
      ],
      "outputs": [
        {
          "value": 100000000,
          "scriptPublicKey": { "version": 0, "script": "20..." }
        }
      ],
      "lockTime": 0,
      "subnetworkId": "0000000000000000000000000000000000000000"
    },
    "allowOrphan": false
  }
}

// Response
{
  "transactionId": "ccdd3344eeff5566..."
}
```

## Notes

<Callout>
Transactions must be fully signed before submission. The node validates all signatures, checks UTXO availability, and verifies transaction mass and fee requirements before accepting the transaction into the mempool.
</Callout>

- If the transaction references UTXOs that are not yet known to the node, it will be rejected unless `allowOrphan` is `true`.
- A successfully submitted transaction is not yet confirmed. It enters the mempool and will be included in a future block by miners.
- Use `GetFeeEstimate` to determine appropriate fee rates before constructing your transaction.
