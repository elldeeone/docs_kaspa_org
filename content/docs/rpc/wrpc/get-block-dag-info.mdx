---
title: "GetBlockDagInfo"
description: "Retrieve comprehensive information about the current state of the BlockDAG."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `networkName` | string | The name of the network (e.g., `kaspa-mainnet`). |
| `blockCount` | u64 | Total number of blocks in the DAG. |
| `headerCount` | u64 | Total number of headers known to the node. |
| `tipHashes` | string[] | Hashes of the current DAG tips (blocks with no children yet). |
| `difficulty` | number | Current mining difficulty. |
| `pastMedianTime` | u64 | The past median time of the virtual block (milliseconds since epoch). |
| `virtualParentHashes` | string[] | Parent hashes of the virtual block. |
| `pruningPointHash` | string | Hash of the current pruning point block. |
| `virtualDaaScore` | u64 | The DAA score of the virtual block. |

## Example

```json
// Request
{
  "method": "getBlockDagInfo",
  "params": {}
}

// Response
{
  "networkName": "kaspa-mainnet",
  "blockCount": 52340000,
  "headerCount": 52340000,
  "tipHashes": [
    "aabb1122...",
    "ccdd3344..."
  ],
  "difficulty": 3456789012345.67,
  "pastMedianTime": 1700000000000,
  "virtualParentHashes": ["aabb1122..."],
  "pruningPointHash": "eeff5566...",
  "virtualDaaScore": 50000000
}
```

## Notes

- The `tipHashes` array shows all current DAG tips. At 10 BPS, there are typically multiple tips at any given moment.
- The `virtualDaaScore` is a monotonically increasing counter used as a logical clock across the network.
- `pastMedianTime` is used for timestamp validation and is more stable than individual block timestamps.
- This method provides a comprehensive snapshot of DAG state and is useful for dashboards and monitoring.
