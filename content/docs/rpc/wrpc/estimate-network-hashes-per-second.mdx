---
title: "EstimateNetworkHashesPerSecond"
description: "Estimate the current network hash rate based on recent block difficulty."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `windowSize` | u32 | Yes | Number of recent blocks to use for the estimation. A larger window gives a smoother estimate. |
| `startHash` | string | No | Hash of the block to start the window from. If omitted, the estimate is computed from the current virtual state. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `networkHashesPerSecond` | u64 | Estimated network hash rate in hashes per second. |

## Example

```json
// Request
{
  "method": "estimateNetworkHashesPerSecond",
  "params": {
    "windowSize": 1000,
    "startHash": "6ef1913d30d5063e040839fcc67cbf02e8e0ae6e4a3cb774c7777043399697f5"
  }
}

// Response
{
  "networkHashesPerSecond": 250000000000000
}
```

## Notes

- The estimate is derived from the difficulty of blocks in the specified window and the time elapsed.
- A larger `windowSize` produces a more stable estimate but is less responsive to sudden hash rate changes.
- `windowSize` must be at least `1000`.
- At 10 BPS, 1000 blocks covers approximately 100 seconds of network activity.
- This method is useful for mining dashboards and network health monitoring.
