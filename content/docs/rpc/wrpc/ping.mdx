---
title: "Ping"
description: "Send a ping to the node for connection keepalive and latency measurement."
---

## Request

No parameters required.

## Response

Empty response on success.

## Example

```json
// Request
{
  "method": "ping",
  "params": {}
}

// Response
{}
```

## Notes

- Use `Ping` to keep WebSocket connections alive through firewalls, load balancers, and proxies that may close idle connections.
- The round-trip time of a ping can be used to measure RPC latency.
- A typical keepalive interval is 30-60 seconds, depending on your network infrastructure's idle timeout settings.
- If the ping fails or times out, the connection is likely broken and should be re-established.
