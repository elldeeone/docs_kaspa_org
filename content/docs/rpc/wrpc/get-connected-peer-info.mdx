---
title: "GetConnectedPeerInfo"
description: "Get detailed information about all currently connected peers."
---

## Request

No parameters required.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `peerInfo` | object[] | Array of connected peer information objects. |
| `peerInfo[].id` | string | Unique identifier for the peer. |
| `peerInfo[].address` | string | The peer's network address (IP:port). |
| `peerInfo[].lastPingDuration` | u64 | Duration of the last ping round-trip in milliseconds. |
| `peerInfo[].isOutbound` | boolean | `true` if the node initiated the connection, `false` if the peer connected to us. |
| `peerInfo[].timeOffset` | i64 | Time offset between the peer's clock and the local clock in milliseconds. |
| `peerInfo[].userAgent` | string | The peer's user agent string (software name and version). |
| `peerInfo[].advertisedProtocolVersion` | u32 | The protocol version advertised by the peer. |
| `peerInfo[].timeConnected` | u64 | Milliseconds since this connection was established. |
| `peerInfo[].isIbdPeer` | boolean | Whether this peer is the node's IBD (Initial Block Download) peer. |

## Example

```json
// Request
{
  "method": "getConnectedPeerInfo",
  "params": {}
}

// Response
{
  "peerInfo": [
    {
      "id": "peer-abc123",
      "address": "192.168.1.100:16111",
      "lastPingDuration": 45,
      "isOutbound": true,
      "timeOffset": -200,
      "userAgent": "rusty-kaspa:0.15.0",
      "advertisedProtocolVersion": 6,
      "timeConnected": 48213,
      "isIbdPeer": false
    }
  ]
}
```

## Notes

- The `lastPingDuration` is useful for diagnosing network latency issues.
- Large `timeOffset` values may indicate clock synchronization problems on remote peers.
- The `userAgent` field shows the software and version of the connected peer.
