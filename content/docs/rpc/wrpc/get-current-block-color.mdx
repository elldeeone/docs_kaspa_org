---
title: "GetCurrentBlockColor"
description: "Determine whether a specific block is currently classified as blue or red by GHOSTDAG."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `hash` | string | Yes | The hash of the block to check. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `blue` | boolean | `true` if the block is blue in GHOSTDAG coloring from the current sink/virtual perspective, `false` if red. |

## Example

```json
// Request
{
  "method": "getCurrentBlockColor",
  "params": {
    "hash": "6ef1913d30d5063e040839fcc67cbf02e8e0ae6e4a3cb774c7777043399697f5"
  }
}

// Response
{
  "blue": true
}
```

## Notes

- In GHOSTDAG, blocks are classified as blue or red relative to the current virtual/sink perspective.
- As the DAG evolves, this classification can change. Treat it as current-node state, not a permanent label.
- This method checks the block's color according to the current virtual's perspective.
