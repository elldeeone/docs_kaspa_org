---
title: "GetUtxosByAddresses"
description: "Retrieve all unspent transaction outputs (UTXOs) for one or more addresses."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `addresses` | string[] | Yes | List of Kaspa addresses to query UTXOs for. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `entries` | object[] | Array of UTXO entries for the queried addresses. |
| `entries[].address` | string | The address this UTXO belongs to. |
| `entries[].outpoint` | object | The outpoint (`transactionId` and `index`) identifying this UTXO. |
| `entries[].utxoEntry` | object | The UTXO data: `amount` (u64, sompi), `scriptPublicKey`, `blockDaaScore` (u64), `isCoinbase` (bool). |

## Example

```json
// Request
{
  "method": "getUtxosByAddresses",
  "params": {
    "addresses": [
      "kaspa:qr0l4g5untavmz2mn5yd4e6qpsh7tg2hfqlfsle8xhncpgy5qxuq9kdarzy4"
    ]
  }
}

// Response
{
  "entries": [
    {
      "address": "kaspa:qr0l4g5untavmz2mn5yd4e6qpsh7tg2hfqlfsle8xhncpgy5qxuq9kdarzy4",
      "outpoint": {
        "transactionId": "aabb1122ccdd3344...",
        "index": 0
      },
      "utxoEntry": {
        "amount": 500000000,
        "scriptPublicKey": { "version": 0, "script": "20..." },
        "blockDaaScore": 50000000,
        "isCoinbase": false
      }
    }
  ]
}
```

## Notes

<Callout>
This method requires the node to have the UTXO index enabled (`--utxoindex` flag). Without it, the node returns an error.
</Callout>

- Values are in **sompi** (1 KAS = 100,000,000 sompi).
- Coinbase UTXOs have a maturity requirement and cannot be spent until sufficient block confirmations have passed.
- The `blockDaaScore` indicates when the UTXO was created, which can be used to calculate its age.
- Querying many addresses at once is more efficient than making separate calls per address.
