---
title: "GetMempoolEntry"
description: "Retrieve a specific transaction entry from the node's mempool by transaction ID."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `txId` | string | Yes | The transaction ID to look up in the mempool. |
| `includeOrphanPool` | boolean | No | Whether to also search the orphan pool. Defaults to `false`. |
| `filterTransactionPool` | boolean | No | If `true`, excludes the main transaction pool and searches only the orphan pool. Defaults to `false`. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `entry` | object | The mempool entry object. |
| `entry.fee` | u64 | Transaction fee in sompi. |
| `entry.mass` | u64 | Transaction mass. |
| `entry.transaction` | object | The full transaction object. |
| `entry.isOrphan` | boolean | Whether the transaction is in the orphan pool. |

## Example

```json
// Request
{
  "method": "getMempoolEntry",
  "params": {
    "txId": "aabb1122ccdd3344...",
    "includeOrphanPool": false,
    "filterTransactionPool": false
  }
}

// Response
{
  "entry": {
    "fee": 5000,
    "mass": 2345,
    "transaction": {
      "version": 0,
      "inputs": [{ "previousOutpoint": { "transactionId": "...", "index": 0 } }],
      "outputs": [{ "value": 100000000, "scriptPublicKey": { "version": 0, "script": "20..." } }],
      "subnetworkId": "0000000000000000000000000000000000000000"
    },
    "isOrphan": false
  }
}
```

## Notes

- Returns an error if the transaction is not found in the mempool (or orphan pool, if searched).
- The `fee` and `mass` fields are useful for determining the transaction's priority relative to other mempool entries.
- Orphan transactions are those whose parent transactions are not yet known to the node.
