---
title: "GetBlockTemplate"
description: "Get a block template for mining, including the header to solve and transactions to include."
---

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `payAddress` | string | Yes | The Kaspa address to receive the coinbase reward. |
| `extraData` | string | No | Arbitrary extra data to include in the coinbase transaction (e.g., miner identification). |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `block` | object | A complete block template ready for mining, containing the header (with fields to solve) and pre-selected transactions. |
| `isSynced` | boolean | Whether the node is synced. Mining on an unsynced node produces blocks that may be rejected. |

## Example

```json
// Request
{
  "method": "getBlockTemplate",
  "params": {
    "payAddress": "kaspa:qr0l4g5untavmz2mn5yd4e6qpsh7tg2hfqlfsle8xhncpgy5qxuq9kdarzy4",
    "extraData": "my-miner-v1.0"
  }
}

// Response
{
  "block": {
    "header": {
      "version": 1,
      "parentsByLevel": [["aabb1122..."]],
      "hashMerkleRoot": "ccdd3344...",
      "acceptedIdMerkleRoot": "eeff5566...",
      "utxoCommitment": "11223344...",
      "timestamp": 1700000000000,
      "bits": 1234567890,
      "nonce": 0,
      "daaScore": 50000000,
      "blueScore": 48000000,
      "blueWork": "1a2b3c...",
      "pruningPoint": "55667788..."
    },
    "transactions": [
      { "version": 0, "inputs": [], "outputs": [{ "value": 50000000000, "scriptPublicKey": { "version": 0, "script": "20..." } }] }
    ]
  },
  "isSynced": true
}
```

## Notes

<Callout>
Always check `isSynced` before mining. If the node is not synced, mined blocks will likely be rejected by the network.
</Callout>

- The miner must find a nonce that satisfies the difficulty target encoded in `bits`.
- Request a new template frequently (at least every few seconds at 10 BPS) to avoid mining on stale DAG tips.
- The `extraData` field is limited in size and must not exceed the maximum allowed length.
