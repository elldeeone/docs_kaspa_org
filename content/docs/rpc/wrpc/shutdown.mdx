---
title: "Shutdown"
description: "Gracefully shut down the Kaspa node."
---

## Request

No parameters required.

## Response

Empty response on success (the node begins shutdown immediately after responding).

## Example

```json
// Request
{
  "method": "shutdown",
  "params": {}
}

// Response
{}
```

## Notes

<Callout>
This is an administrative method that immediately begins a graceful shutdown of the node process. Ensure RPC access is restricted to prevent unauthorized shutdown.
</Callout>

- The node will stop accepting new connections, flush pending data to disk, and terminate.
- Any in-flight RPC requests from other clients may not receive responses.
- The graceful shutdown process allows the node to persist its state so it can resume quickly on restart.
- This method does not require confirmation. Once called, the shutdown proceeds immediately.
