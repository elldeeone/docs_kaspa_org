---
title: "Shutdown"
description: "Gracefully shut down the Kaspa node."
---

## Request

No parameters required.

## Response

Empty response on success (shutdown is triggered after the response, with a short delay).

## Example

```json
// Request
{
  "method": "shutdown",
  "params": {}
}

// Response
{}
```

## Notes

<Callout>
This is an administrative method and is unavailable in safe RPC mode. Run the node with `--unsaferpc` to call it. Ensure RPC access is restricted to prevent unauthorized shutdown.
</Callout>

- The service schedules shutdown shortly after responding (currently about 1 second) so the caller can receive the response.
- Any in-flight RPC requests from other clients may not receive responses.
- This method does not require confirmation. Once called, the shutdown proceeds immediately.
