## What is gRPC?

gRPC is a high-performance, language-neutral remote procedure call framework built on HTTP/2 and Protocol Buffers (protobuf). It provides strongly-typed service definitions, automatic client/server code generation, and efficient binary serialization. Kaspa nodes expose a gRPC interface alongside the primary wRPC (WebSocket RPC) interface, giving infrastructure operators and backend developers an alternative transport for node communication.

## When to Use gRPC vs wRPC

| Use Case | Recommended Protocol | Reason |
|---|---|---|
| Browser applications | wRPC | gRPC is not natively supported in browsers |
| Node.js backends | wRPC or gRPC | Both are viable; choose based on your existing tooling |
| Rust infrastructure | gRPC | Native tonic support, strong typing |
| Go / Python / Java backends | gRPC | Standard protobuf/gRPC toolchains and code generation |
| High-frequency data pipelines | gRPC | Binary serialization, HTTP/2 transport |
| Exchange integrations | gRPC | Server-to-server integration with typed contracts |
| Mobile applications | wRPC | WebSocket transport is typically simpler in mobile stacks |

<Callout type="info">
For most application developers, the wRPC interface or the WASM SDK will be simpler to work with. gRPC is best suited for server-to-server communication, existing gRPC infrastructure, and scenarios where code generation and strong typing are priorities.
</Callout>

## Connection Details

Kaspa nodes listen for gRPC connections on the following default ports:

| Network | Default gRPC Port |
|---|---|
| Mainnet | 16110 |
| All testnets (testnet-10, testnet-11, etc.) | 16210 |
| Simnet | 16510 |
| Devnet | 16610 |

Connect to a local mainnet node:

```
grpc://127.0.0.1:16110
```

<Callout>
gRPC connections require direct access to a Kaspa node. Public resolver infrastructure is focused on wRPC endpoints, so gRPC deployments are typically self-hosted or privately exposed.
</Callout>

## Authentication

Kaspa's gRPC interface does not include built-in authentication, and kaspad does not expose native TLS endpoint flags for gRPC. Access control is handled at the network/proxy layer. When deploying in production:

- Bind the gRPC port to `127.0.0.1` or a private network interface rather than `0.0.0.0`.
- Use a firewall or VPN to restrict access to trusted clients.
- If exposing over the internet, place a TLS-terminating reverse proxy (such as Envoy or nginx with gRPC support) in front of the node.

## Available Methods

The gRPC interface exposes the same set of RPC methods as wRPC. All query, mutation, and subscription operations are available through both transports. Key method categories include:

- **Block and DAG queries** -- `getBlock`, `getBlockDagInfo`, `getBlocks`, `getHeaders`
- **Transaction operations** -- `submitTransaction`, `getMempoolEntry`, `getMempoolEntries`
- **UTXO and balance queries** -- `getUtxosByAddresses`, `getBalanceByAddress`, `getBalancesByAddresses`
- **Network information** -- `getInfo`, `getConnectedPeerInfo`, `getPeerAddresses`, `estimateNetworkHashesPerSecond`, `getCoinSupply`
- **Subscriptions** -- `notifyBlockAdded`, `notifyUtxosChanged`, `notifyVirtualChainChanged`, `notifyVirtualDaaScoreChanged`, and more

## Language Support

gRPC supports code generation for languages with protobuf compiler plugins. Kaspa schemas can be generated for:

- **Rust** -- Native support via the `tonic` crate (used internally by rusty-kaspa)
- **Go** -- Via `protoc-gen-go` and `protoc-gen-go-grpc`
- **Python** -- Via `grpcio-tools`
- **Java / Kotlin** -- Via the official gRPC-Java plugin
- **C# / .NET** -- Via the Grpc.Tools NuGet package
- **C++** -- Via the native protobuf compiler
- **TypeScript / Node.js** -- Via `@grpc/grpc-js` and `ts-proto` or `grpc-tools`

## Example: Connecting in Rust

Rust is the native language of rusty-kaspa, and gRPC support is built on the `tonic` crate.

```rust
use kaspa_grpc_client::GrpcClient;
use kaspa_rpc_core::api::rpc::RpcApi;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = GrpcClient::connect("grpc://127.0.0.1:16110".to_string()).await?;

    let dag_info = client.get_block_dag_info().await?;
    println!("Network: {}", dag_info.network);
    println!("Block count: {}", dag_info.block_count);
    println!("DAA score: {}", dag_info.virtual_daa_score);

    client.disconnect().await?;
    Ok(())
}
```

## Example: Connecting in Python

```python
import grpc
from generated import messages_pb2, messages_pb2_grpc

def requests():
    yield messages_pb2.KaspadRequest(
        id=1,
        getBlockDagInfoRequest=messages_pb2.GetBlockDagInfoRequestMessage(),
    )

channel = grpc.insecure_channel("127.0.0.1:16110")
stub = messages_pb2_grpc.RPCStub(channel)
stream = stub.MessageStream(requests())

for response in stream:
    if response.HasField("getBlockDagInfoResponse"):
        info = response.getBlockDagInfoResponse
        if info.error and info.error.message:
            raise RuntimeError(info.error.message)
        print(f"Network: {info.networkName}")
        print(f"Block count: {info.blockCount}")
        print(f"DAA score: {info.virtualDaaScore}")
        break
```

## Example: Connecting in Go

```go
package main

import (
    "context"
    "fmt"
    "log"

    pb "your-module/generated/proto"
    "google.golang.org/grpc"
    "google.golang.org/grpc/credentials/insecure"
)

func main() {
    conn, err := grpc.Dial(
        "127.0.0.1:16110",
        grpc.WithTransportCredentials(insecure.NewCredentials()),
    )
    if err != nil {
        log.Fatalf("Failed to connect: %v", err)
    }
    defer conn.Close()

    client := pb.NewRPCClient(conn)
    stream, err := client.MessageStream(context.Background())
    if err != nil {
        log.Fatalf("MessageStream failed: %v", err)
    }

    err = stream.Send(&pb.KaspadRequest{
        Id: 1,
        Payload: &pb.KaspadRequest_GetBlockDagInfoRequest{
            GetBlockDagInfoRequest: &pb.GetBlockDagInfoRequestMessage{},
        },
    })
    if err != nil {
        log.Fatalf("Send failed: %v", err)
    }

    resp, err := stream.Recv()
    if err != nil {
        log.Fatalf("Recv failed: %v", err)
    }

    msg, ok := resp.Payload.(*pb.KaspadResponse_GetBlockDagInfoResponse)
    if !ok {
        log.Fatalf("Unexpected payload type: %T", resp.Payload)
    }
    if msg.GetBlockDagInfoResponse().GetError() != nil &&
        msg.GetBlockDagInfoResponse().GetError().GetMessage() != "" {
        log.Fatalf("RPC error: %s", msg.GetBlockDagInfoResponse().GetError().GetMessage())
    }

    info := msg.GetBlockDagInfoResponse()
    fmt.Printf("Network: %s\n", info.GetNetworkName())
    fmt.Printf("Block count: %d\n", info.GetBlockCount())
    fmt.Printf("DAA score: %d\n", info.GetVirtualDaaScore())
}
```
