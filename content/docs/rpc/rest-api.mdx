## Overview

The Kaspa REST API provides simple HTTP endpoints for querying blockchain data without running a node or using an SDK. It is served by the [kaspa-rest-server](https://github.com/kaspa-ng/kaspa-rest-server), an open-source indexing server that connects to a Kaspa node via wRPC.

**Public instance:** [`https://api.kaspa.org`](https://api.kaspa.org)

<Callout type="info">
The public API at `api.kaspa.org` is provided for development and light usage. For production applications that process real value, run your own instance of the REST server connected to your own node.
</Callout>

## Endpoint Categories

| Category | Example Endpoints | Description |
|---|---|---|
| **Addresses** | `/addresses/{address}/balance`, `/addresses/{address}/utxos`, `/addresses/{address}/full-transactions` | Balance queries, UTXO lookups, transaction history |
| **Blocks** | `/blocks/{blockHash}`, `/blocks` | Block retrieval by hash, range queries by low hash |
| **Transactions** | `/transactions/{transactionId}`, `POST /transactions` | Transaction lookup and submission |
| **Network Info** | `/info/blockdag`, `/info/coinsupply`, `/info/hashrate`, `/info/fee-estimate`, `/info/health` | DAG state, supply, hashrate, fee estimates, health checks |
| **Virtual Chain** | `/virtual-chain` | Virtual-chain blocks and transactions by blue score |

## Quick Examples

```bash
# Get balance for an address (returns sompi; divide by 10^8 for KAS)
curl https://api.kaspa.org/addresses/kaspa:qqkqkzjvr7zwxx.../balance

# Get current DAG info
curl https://api.kaspa.org/info/blockdag

# Get coin supply
curl https://api.kaspa.org/info/coinsupply

# Get fee estimate
curl https://api.kaspa.org/info/fee-estimate

# Submit a signed transaction
curl -X POST https://api.kaspa.org/transactions \
  -H "Content-Type: application/json" \
  -d '{"transaction": { ... }}'
```

## OpenAPI Specification

The REST server exposes an OpenAPI (Swagger) specification. When running your own instance, the spec is available at the server root. A copy of the spec is also maintained in the [docs repository](https://github.com/kaspa-org/docs/tree/main/audit/kaspa_openapi.json).

## Running Your Own Instance

For production use, deploy the REST server yourself:

```bash
git clone https://github.com/kaspa-ng/kaspa-rest-server
cd kaspa-rest-server
# Follow the README for build and configuration
```

The server connects to a Kaspa node via wRPC and indexes data into a database for fast query serving.
