## Overview

The virtual-daa-score-changed subscription notifies your application whenever the virtual DAA (Difficulty Adjustment Algorithm) score changes. The DAA score is a monotonically increasing consensus clock used for difficulty adjustment, time-based lock conditions, and coinbase maturity tracking.

## Subscribe

```typescript
await rpc.subscribeVirtualDaaScoreChanged();
```

**Wire contract note:** wRPC notification control uses `subscribe` / `unsubscribe` with a `VirtualDaaScoreChanged` scope payload. gRPC uses `NotifyVirtualDaaScoreChangedRequestMessage` with `command` set to `NOTIFY_START` or `NOTIFY_STOP`.

## Unsubscribe

```typescript
await rpc.unsubscribeVirtualDaaScoreChanged();
```

## Notification Format

```json
{
  "virtualDaaScore": 52345680
}
```

### Fields

| Field | Type | Description |
|---|---|---|
| `virtualDaaScore` | integer | The current virtual DAA score |

## Event Handling

```typescript
rpc.addEventListener("virtual-daa-score-changed", (event) => {
  const daaScore = event.data.virtualDaaScore;
  console.log(`DAA score: ${daaScore}`);
});
```

## What the DAA Score Represents

DAA score tracks consensus progression for timing-sensitive rules. Unlike blue score, it is used directly in lock-time and maturity logic.

Key properties:

- **Monotonically increasing** -- The DAA score never decreases.
- **Not a fixed seconds counter** -- DAA progression should not be treated as a strict 1:1 wall-clock mapping.
- **Used for lock times** -- Transaction `lockTime` values below 500,000,000,000 are interpreted as DAA scores.
- **Used for coinbase maturity** -- Coinbase transaction outputs cannot be spent until a certain DAA score depth is reached.

## Use Cases

- **Heartbeat / liveness check** -- If the DAA score stops increasing, the node may be disconnected or the network may be stalled.
- **Time-oriented heuristics** -- Track progression for timing-sensitive workflows without relying solely on block timestamps.
- **Lock time monitoring** -- Track when time-locked transactions become spendable.
- **UI progress display** -- Show a real-time ticker of network progression.

<Callout>
This subscription is lightweight and useful for liveness/progression monitoring, but DAA increments are not guaranteed to map to fixed wall-clock intervals.
</Callout>
