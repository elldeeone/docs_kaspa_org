## Overview

The sink-blue-score-changed subscription notifies your application whenever the blue score of the DAG sink (the virtual selected parent) changes. Blue score is a monotonically increasing GHOSTDAG score associated with block ordering and progression.

## Subscribe

```typescript
await rpc.subscribeSinkBlueScoreChanged();
```

**Wire contract note:** wRPC notification control uses `subscribe` / `unsubscribe` with a `SinkBlueScoreChanged` scope payload. gRPC uses `NotifySinkBlueScoreChangedRequestMessage` with `command` set to `NOTIFY_START` or `NOTIFY_STOP`.

## Unsubscribe

```typescript
await rpc.unsubscribeSinkBlueScoreChanged();
```

## Notification Format

```json
{
  "sinkBlueScore": 48234569
}
```

### Fields

| Field | Type | Description |
|---|---|---|
| `sinkBlueScore` | integer | The current blue score of the virtual selected parent |

## Event Handling

```typescript
rpc.addEventListener("sink-blue-score-changed", (event) => {
  const blueScore = event.data.sinkBlueScore;
  console.log(`Blue score: ${blueScore}`);
});
```

## Blue Score vs DAA Score

While both are monotonically increasing, blue score and DAA score serve different purposes:

| Property | Blue Score | DAA Score |
|---|---|---|
| **Meaning** | GHOSTDAG blue score of the selected sink block | Difficulty-adjustment clock used by consensus rules |
| **Increments by** | Variable increments (not fixed to +1) | Variable increments |
| **Use** | Confirmation depth, chain progression | Timing, difficulty adjustment, lock times |
| **Subscription** | `notifySinkBlueScoreChanged` | `notifyVirtualDaaScoreChanged` |

## Use Cases

- **Confirmation depth** -- Calculate how many blue blocks have been added since a transaction was accepted. More blue blocks means deeper confirmation.
- **Progress indicators** -- Display chain progression in a UI.
- **Sync monitoring** -- Track how quickly the node is catching up during initial block download.

<Callout type="info">
Blue score is monotonic, but increment size is not fixed. Use it as an ordering/progression metric, not as a wall-clock substitute.
</Callout>
