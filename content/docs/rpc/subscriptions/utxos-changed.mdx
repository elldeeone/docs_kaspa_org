## Overview

The `notifyUtxosChanged` subscription notifies your application whenever the UTXO set changes for one or more watched addresses. Each notification reports which UTXOs were added (received) and which were removed (spent). This is the primary mechanism for real-time balance tracking in Kaspa.

## Subscribe

Subscribe with one or more addresses to watch:

```typescript
await rpc.subscribeUtxosChanged([
  "kaspa:qr35ennsep3hxfe7lnz5ee7j5jgmkjswsn35ennsep3hxfe7lkaspadev",
  "kaspa:qzu8yngf4ross8dylan5en8hy9emr3vysjq0hpve5yhnf87s3hq7qv6lvl9"
]);
```

**RPC request:**

```json
{
  "method": "notifyUtxosChanged",
  "params": {
    "addresses": [
      "kaspa:qr35ennsep3hxfe7lnz5ee7j5jgmkjswsn35ennsep3hxfe7lkaspadev"
    ]
  }
}
```

## Unsubscribe

```typescript
await rpc.unsubscribeUtxosChanged([
  "kaspa:qr35ennsep3hxfe7lnz5ee7j5jgmkjswsn35ennsep3hxfe7lkaspadev"
]);
```

### Fields

| Field | Type | Description |
|---|---|---|
| `added` | array | New UTXOs created for the watched addresses |
| `removed` | array | UTXOs spent from the watched addresses |
| `added[].address` | string | The address that received the UTXO |
| `added[].outpoint` | object | Transaction ID and output index identifying the UTXO |
| `added[].utxoEntry.amount` | string | UTXO value in sompi |
| `added[].utxoEntry.blockDaaScore` | integer | DAA score of the block containing the transaction |
| `added[].utxoEntry.isCoinbase` | boolean | Whether this UTXO comes from a coinbase transaction |

## Event Handling

```typescript
rpc.addEventListener("utxos-changed", (event) => {
  const { added, removed } = event.data;

  let balanceChange = BigInt(0);

  for (const utxo of added) {
    const amount = BigInt(utxo.utxoEntry.amount);
    balanceChange += amount;
    console.log(`Received ${amount} sompi at ${utxo.address}`);
  }

  for (const utxo of removed) {
    const amount = BigInt(utxo.utxoEntry.amount);
    balanceChange -= amount;
    console.log(`Spent ${amount} sompi from ${utxo.address}`);
  }

  console.log(`Net balance change: ${balanceChange} sompi`);
});
```

<Callout type="info">
UTXO amounts can be large numbers. Use `BigInt` in JavaScript/TypeScript (or equivalent large integer types in other languages) to avoid precision loss when performing arithmetic on sompi values.
</Callout>

## Use Cases

- **Wallet balance tracking** -- Maintain a real-time balance by summing added UTXOs and subtracting removed UTXOs.
- **Payment detection** -- Watch a merchant address for incoming payments and trigger order fulfillment when a UTXO appears.
- **Exchange deposit monitoring** -- Watch deposit addresses for incoming funds and credit user accounts.
- **UTXO management** -- Track the UTXO set for an address to optimize transaction construction and consolidation.

<Callout>
A UTXO appearing in the `added` array means it exists in the current virtual UTXO set. However, it may still be subject to reorganization until it reaches sufficient confirmation depth. For high-value transactions, wait for multiple DAA score increments before treating the payment as final.
</Callout>

## Watching Multiple Addresses

You can subscribe to changes for hundreds of addresses in a single subscription call. This is useful for HD wallets that derive many addresses:

```typescript
// Watch all derived addresses from an HD wallet
const addresses = wallet.getAllAddresses(); // Returns array of address strings
await rpc.subscribeUtxosChanged(addresses);
```

To add more addresses to an existing subscription, call `subscribeUtxosChanged` again with the new addresses. To stop watching specific addresses, use `unsubscribeUtxosChanged` with those addresses.
