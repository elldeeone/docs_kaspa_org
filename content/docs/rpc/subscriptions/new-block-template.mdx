## Overview

Mining pools use the new-block-template subscription to get notified whenever the
node has a new block template ready. Treat this as a signal to fetch a fresh template via
`getBlockTemplate`. In current node code, this notification is emitted during virtual-state
processing.

## Subscribe

```typescript
await rpc.subscribeNewBlockTemplate();
```

**Wire contract note:** wRPC notification control uses `subscribe` / `unsubscribe` with a `NewBlockTemplate` scope payload. gRPC uses `NotifyNewBlockTemplateRequestMessage` with `command` set to `NOTIFY_START` or `NOTIFY_STOP`.

The WASM subscription call returns success/failure (`Result<()>`).

## Notification Format

The notification itself is empty -- it signals that a new template is available. The miner
must then call `getBlockTemplate` to retrieve the full template.

```json
{}
```

<Callout type="info">
The notification does not include template data. This avoids sending large payloads that
may be superseded before the miner processes them. Instead, call `getBlockTemplate`
after each notification to fetch the current template.
</Callout>

## Unsubscribe

```typescript
await rpc.unsubscribeNewBlockTemplate();
```

## Code Example

```typescript
import { RpcClient, Resolver, Encoding } from "kaspa-wasm";

async function startMiningListener() {
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  await rpc.subscribeNewBlockTemplate();

  rpc.addEventListener("new-block-template", async () => {
    const template = await rpc.getBlockTemplate({
      payAddress: "kaspa:qr...",
      extraData: "my-pool-v1.0",
    });
    console.log(`New template - DAA: ${template.block.header.daaScore}`);
    // Pass template.block to mining hardware/software
  });

  console.log("Listening for new block templates...");
  await new Promise(() => {});
}

startMiningListener().catch(console.error);
```

## Use Cases

- **Mining pools** -- Update work for connected miners immediately when the DAG tip changes, minimizing stale shares.
- **Solo mining** -- Fetch fresh templates from your own node to mine blocks directly.
- **Stratum servers** -- Convert Kaspa block templates into Stratum-compatible work units for mining hardware.

<Callout type="warn">
Templates can update frequently. Mining software should minimize latency between receiving
the notification and fetching/dispatching new work to reduce stale effort.
</Callout>
