## Overview

The block-added subscription notifies your application every time a new block is added to the DAG. At Kaspa's current rate of 10 blocks per second, this is one of the highest-frequency subscription types.

## Subscribe

```typescript
await rpc.subscribeBlockAdded();
```

**Wire contract note:** wRPC notification control uses `subscribe` / `unsubscribe` with a `BlockAdded` scope payload. gRPC uses `NotifyBlockAddedRequestMessage` with `command` set to `NOTIFY_START` or `NOTIFY_STOP`.

## Unsubscribe

```typescript
await rpc.unsubscribeBlockAdded();
```

## Event Handling

```typescript
rpc.addEventListener("block-added", (event) => {
  const block = event.data.block;
  const hash = block.verboseData.hash;
  const daaScore = block.header.daaScore;
  const txCount = block.transactions.length;
  const isChainBlock = block.verboseData.isChainBlock;

  console.log(`Block ${hash.substring(0, 12)}...`);
  console.log(`  DAA: ${daaScore}, Txs: ${txCount}, Chain: ${isChainBlock}`);
});
```

## Use Cases

- **Block explorers** -- Display new blocks in real time as they arrive.
- **Mining monitors** -- Track block production rate and your own mined blocks.
- **Transaction tracking** -- Check if a specific transaction appears in a new block.
- **Network health dashboards** -- Monitor block rate and detect anomalies.

<Callout>
At 10 BPS, you will receive approximately 10 notifications per second. Ensure your handler is efficient and non-blocking. If you only need to know about chain progression rather than every individual block, consider using [Virtual Chain Changed](/docs/rpc/subscriptions/virtual-chain-changed) or [Virtual DAA Score Changed](/docs/rpc/subscriptions/virtual-daa-score-changed) instead.
</Callout>
