---
title: Network Info Endpoints
description: "REST API endpoints for Kaspa network information — supply, hashrate, DAG info, and fee estimates."
---

## Base URL

```
https://api.kaspa.org
```

These endpoints provide read-only information about the Kaspa network's current state. They are useful for dashboards, explorers, analytics tools, and any application that needs to display network statistics.

## GET /info/blockdag

Returns detailed information about the current state of the block DAG.

**Request:**

```
GET https://api.kaspa.org/info/blockdag
```

**Response:**

```json
{
  "networkName": "kaspa-mainnet",
  "blockCount": "58234192",
  "headerCount": "58234192",
  "tipHashes": [
    "8d3f2e1a9b7c4d5e6f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2",
    "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2"
  ],
  "difficulty": 1.234567890123e+15,
  "pastMedianTime": "1700000000000",
  "virtualParentHashes": [
    "8d3f2e1a9b7c4d5e6f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2"
  ],
  "pruningPointHash": "d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3d4",
  "virtualDaaScore": "52345678"
}
```

| Field | Description |
|---|---|
| `networkName` | Network identifier (e.g., `kaspa-mainnet`) |
| `blockCount` | Total number of blocks in the DAG |
| `headerCount` | Total number of block headers (may differ if bodies are pruned) |
| `tipHashes` | Current DAG tip block hashes |
| `difficulty` | Current mining difficulty |
| `pastMedianTime` | Median timestamp of recent blocks (Unix milliseconds) |
| `virtualParentHashes` | Parent hashes of the virtual block |
| `pruningPointHash` | Hash of the current pruning point |
| `virtualDaaScore` | Current virtual DAA score |

## GET /info/network

Returns general network information from the node.

**Request:**

```
GET https://api.kaspa.org/info/network
```

**Response:**

```json
{
  "networkName": "kaspa-mainnet",
  "blockCount": "58234192",
  "headerCount": "58234192",
  "tipHashes": [
    "8d3f2e1a9b7c4d5e6f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2"
  ],
  "difficulty": 1.234567890123e+15,
  "pastMedianTime": "1700000000000",
  "virtualParentHashes": [
    "8d3f2e1a9b7c4d5e6f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2"
  ],
  "pruningPointHash": "d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3d4",
  "virtualDaaScore": "52345678",
  "sink": "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2"
}
```

<Callout type="info">
This endpoint returns the same data as the wRPC `getBlockDagInfo` method. It provides a snapshot of the DAG state including tip hashes, difficulty, virtual DAA score, and the sink (the current selected tip of the virtual chain).
</Callout>

## GET /info/coinsupply

Returns the current coin supply breakdown.

**Request:**

```
GET https://api.kaspa.org/info/coinsupply
```

**Response:**

```json
{
  "circulatingSupply": "2723867870846334647",
  "maxSupply": "2870403560500000000"
}
```

Values are in sompi. Divide by 10^8 to get KAS.

## GET /info/coinsupply/circulating

Returns only the circulating supply as a plain number, useful for integrations with market data aggregators.

**Request:**

```
GET https://api.kaspa.org/info/coinsupply/circulating?in_billion=false
```

**Response:**

```
24600000000.00000000
```

## GET /info/coinsupply/total

Returns the total supply.

**Request:**

```
GET https://api.kaspa.org/info/coinsupply/total
```

**Response:**

```
24600000000.00000000
```

<Callout>
Kaspa has a fixed maximum supply of approximately 28.7 billion KAS. The `maxSupply` field in the `/info/coinsupply` response shows this value. The emission schedule follows a chromatic (musical half-note) curve, with the block reward halving approximately once per year.
</Callout>

## GET /info/hashrate

Returns the estimated network hashrate.

**Request:**

```
GET https://api.kaspa.org/info/hashrate
```

**Query Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `windowSize` | integer | Number of blocks to average over (optional) |

**Response:**

```json
{
  "hashrate": 1.23e+18
}
```

The hashrate is returned in hashes per second.

## GET /info/fee-estimate

Returns the current fee estimate for transaction inclusion.

**Request:**

```
GET https://api.kaspa.org/info/fee-estimate
```

**Response:**

```json
{
  "normalBuckets": [
    {
      "feerate": 1.0,
      "estimatedSeconds": 1.0
    }
  ],
  "lowBuckets": [
    {
      "feerate": 1.0,
      "estimatedSeconds": 5.0
    }
  ],
  "priorityBucket": {
    "feerate": 10.0,
    "estimatedSeconds": 0.5
  }
}
```

<Callout type="info">
Fee estimates are returned as fee rate values in sompi per gram of mass. Under normal network conditions, Kaspa's high throughput (10 BPS) means the minimum fee rate of 1 sompi/gram is usually sufficient. Higher fee rates are only needed during periods of exceptional congestion.
</Callout>

## GET /info/health

Returns the health status of the REST API server and the underlying node.

**Request:**

```
GET https://api.kaspa.org/info/health
```

**Response:**

```json
{
  "kaspadServers": [
    {
      "kaspadHost": "wrpc",
      "serverVersion": "1.1.0",
      "isUtxoIndexed": true,
      "isSynced": true,
      "p2pId": "a1b2c3d4e5f6..."
    }
  ]
}
```

Use this endpoint for health checks and monitoring. The response includes information about each connected kaspad server, including its sync status, version, and whether the UTXO index is enabled. A node that is not synced may return stale data.

## GET /info/virtual-chain-blue-score

Returns the current blue score of the virtual chain's selected parent.

**Request:**

```
GET https://api.kaspa.org/info/virtual-chain-blue-score
```

**Response:**

```json
{
  "blueScore": 48234567
}
```

The blue score is a monotonically increasing value that serves as Kaspa's analogue to block height. It represents the number of blue blocks in the selected parent chain from genesis to the current virtual block.

## Error Responses

| Status Code | Meaning |
|---|---|
| `200` | Success |
| `500` | Internal server error or node unavailable |
| `503` | Node is syncing and cannot serve requests |
