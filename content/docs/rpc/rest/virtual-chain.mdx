## Base URL

```
https://api.kaspa.org
```

## GET /virtual-chain

Returns virtual-chain blocks (with transactions) starting at a blue-score lower bound.

**Request:**

```
GET https://api.kaspa.org/virtual-chain?blueScoreGte=365813900&limit=10&resolveInputs=false&includeCoinbase=true
```

**Query Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `blueScoreGte` | integer | Required lower bound for blue score (documented as divisible by `limit`) |
| `limit` | integer | Optional page size. Allowed values: `10` or `100` (default: `10`) |
| `resolveInputs` | boolean | Include resolved previous-outpoint details in transaction inputs (default: `false`) |
| `includeCoinbase` | boolean | Include coinbase transactions (default: `true`) |

### Response Fields

| Field | Type | Description |
|---|---|---|
| `hash` | string | Virtual-chain block hash |
| `blue_score` | integer | Block blue score |
| `daa_score` | integer | Block DAA score |
| `timestamp` | integer | Block timestamp (epoch milliseconds) |
| `transactions` | array | Transactions associated with the block |
| `transactions[].transaction_id` | string | Transaction ID |
| `transactions[].is_accepted` | boolean | Whether the transaction is accepted |
| `transactions[].inputs` | array | Transaction inputs (optional, depends on endpoint options/data) |
| `transactions[].outputs` | array | Transaction outputs |

<Callout type="warn">
This endpoint is marked experimental in the OpenAPI summary and may change.
</Callout>

## Pagination / Iteration

To iterate forward through virtual-chain data, issue repeated requests with increasing `blueScoreGte` values and a fixed `limit` (`10` or `100`).

For reorg-aware chain-delta workflows (`addedChainBlockHashes` / `removedChainBlockHashes`), use node RPC methods such as `getVirtualChainFromBlock` over wRPC/gRPC and/or the `notifyVirtualChainChanged` subscription.

## Error Responses

| Status Code | Meaning |
|---|---|
| `200` | Success |
| `422` | Validation error (invalid query params) |
| `500` | Internal server error |
