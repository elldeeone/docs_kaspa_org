## Prerequisites

- **Kaspa WASM SDK** installed (`npm install kaspa-wasm`)
- **A wallet with many UTXOs** -- common for miners who accumulate block rewards across many small outputs

<Callout>
Mining payouts and frequent small payments can fragment your wallet into hundreds or thousands of small UTXOs. Each transaction can only include a limited number of inputs before exceeding the 100,000 maximum transaction mass. Consolidation merges these small UTXOs into fewer, larger ones, making future transactions faster and cheaper.
</Callout>

## Code

The following example queries UTXOs for an address and performs consolidation:

```typescript
import {
  RpcClient,
  Resolver,
  Encoding,
  Mnemonic,
  XPrv,
  UtxoProcessor,
  UtxoContext,
  createTransactions,
  sompiToKaspaString,
} from "kaspa-wasm";

async function consolidateUtxos() {
  // 1. Connect to a Kaspa node
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  // 2. Set up wallet
  const mnemonic = new Mnemonic("your twenty four word mnemonic ...");
  const seed = mnemonic.toSeed("");
  const xprv = new XPrv(seed);
  const account = xprv.derivePath("m/44'/111111'/0'");
  const privateKey = account.derivePath("0/0").toPrivateKey();
  const address = privateKey.toPublicKey().toAddress("mainnet").toString();

  // 3. Set up UTXO tracking
  const processor = new UtxoProcessor({ rpc, networkId: "mainnet" });
  const context = new UtxoContext({ processor });
  await processor.start();
  await context.trackAddresses([address]);
  await new Promise((resolve) => setTimeout(resolve, 3000));

  // 4. Check current UTXO state
  const balance = context.balance;
  console.log("Current balance:", sompiToKaspaString(balance?.mature ?? 0n), "KAS");
  console.log("Pending balance:", sompiToKaspaString(balance?.pending ?? 0n), "KAS");

  // Query raw UTXOs for analysis
  const utxoResponse = await rpc.getUtxosByAddresses([address]);
  const utxoCount = utxoResponse.entries.length;
  console.log("Total UTXOs:", utxoCount);

  if (utxoCount <= 2) {
    console.log("No consolidation needed (2 or fewer UTXOs).");
    await processor.stop();
    await rpc.disconnect();
    return;
  }

  // 5. Analyze UTXO distribution
  const amounts = utxoResponse.entries.map(
    (entry) => entry.amount
  );
  amounts.sort((a, b) => Number(a - b));

  console.log("\nUTXO distribution:");
  console.log("  Smallest:", sompiToKaspaString(amounts[0]), "KAS");
  console.log("  Largest:", sompiToKaspaString(amounts[amounts.length - 1]), "KAS");
  console.log(
    "  Median:",
    sompiToKaspaString(amounts[Math.floor(amounts.length / 2)]),
    "KAS"
  );

  // 6. Consolidate by sending the full balance to yourself
  //    createTransactions handles the compound transaction chain
  const totalBalance = balance?.mature ?? 0n;

  try {
    const { transactions, summary } = await createTransactions({
      entries: context,
      outputs: [
        {
          address: address,
          amount: totalBalance,
        },
      ],
      changeAddress: address,
      priorityFee: 0n,
    });

    console.log("\nConsolidation plan:");
    console.log("  Transactions needed:", transactions.length);
    console.log("  Summary:", summary);

    // 7. Sign and submit each transaction in order
    for (let i = 0; i < transactions.length; i++) {
      const tx = transactions[i];
      tx.sign([privateKey]);
      const txId = await tx.submit(rpc);
      console.log(`  Transaction ${i + 1}/${transactions.length}: ${txId}`);
    }

    console.log("\nConsolidation complete.");
    console.log(
      "Your UTXOs have been merged. The final UTXO will be available",
      "after the last transaction confirms."
    );
  } catch (err) {
    if (err.message?.includes("Insufficient funds")) {
      // This can happen if balance is too small to cover fees
      // Try sending a smaller amount
      console.log(
        "Balance too small to consolidate after fees.",
        "Try consolidating a portion of UTXOs instead."
      );
    } else {
      throw err;
    }
  }

  // 8. Clean up
  await processor.stop();
  await rpc.disconnect();
}

// Utility: Consolidate UTXOs across multiple addresses in an HD wallet
async function consolidateHdWallet(
  mnemonicPhrase: string,
  addressCount: number = 20
) {
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  const mnemonic = new Mnemonic(mnemonicPhrase);
  const seed = mnemonic.toSeed("");
  const xprv = new XPrv(seed);
  const account = xprv.derivePath("m/44'/111111'/0'");

  // Derive multiple addresses and their keys
  const keys = [];
  const addresses = [];
  for (let i = 0; i < addressCount; i++) {
    const key = account.derivePath(`0/${i}`).toPrivateKey();
    keys.push(key);
    addresses.push(key.toPublicKey().toAddress("mainnet").toString());
  }

  // Track all addresses
  const processor = new UtxoProcessor({ rpc, networkId: "mainnet" });
  const context = new UtxoContext({ processor });
  await processor.start();
  await context.trackAddresses(addresses);
  await new Promise((resolve) => setTimeout(resolve, 5000));

  const balance = context.balance;
  console.log("Total balance across", addressCount, "addresses:");
  console.log("  Mature:", sompiToKaspaString(balance?.mature ?? 0n), "KAS");

  // Consolidate everything to the first address
  const targetAddress = addresses[0];
  const totalBalance = balance?.mature ?? 0n;

  if (totalBalance === 0n) {
    console.log("No balance to consolidate.");
    await processor.stop();
    await rpc.disconnect();
    return;
  }

  const { transactions } = await createTransactions({
    entries: context,
    outputs: [{ address: targetAddress, amount: totalBalance }],
    changeAddress: targetAddress,
    priorityFee: 0n,
  });

  for (let i = 0; i < transactions.length; i++) {
    const tx = transactions[i];
    tx.sign(keys); // Sign with all keys since inputs may come from any address
    const txId = await tx.submit(rpc);
    console.log(`Transaction ${i + 1}/${transactions.length}: ${txId}`);
  }

  await processor.stop();
  await rpc.disconnect();
}

consolidateUtxos().catch(console.error);
```

## Explanation

### Why consolidation matters

Each transaction input adds to the transaction's mass:

- **Compute mass**: Each input requires one signature verification (1,000 mass per sigop)
- **Transactional mass**: Each input adds roughly 70--80 bytes to the serialized size

With a maximum transaction mass of 100,000, the number of inputs that fit in one transaction depends on script and transaction composition. If your wallet has many UTXOs, you may not be able to spend all of them in one transaction. The SDK solves this by producing a **chain of compound transactions** that progressively consolidate UTXOs.

### How compound transactions work

When `createTransactions` detects that the wallet needs more UTXOs than a single transaction can accommodate, it automatically creates a chain:

1. **Transaction 1**: Combines the first batch of UTXOs into one or two outputs
2. **Transaction 2**: Combines those outputs with the next batch
3. **... and so on** until all UTXOs are consolidated
4. **Final transaction**: Sends the consolidated amount to the destination

Each transaction in the chain depends on the outputs of the previous one, so they must be signed and submitted in order.

<Callout type="info">
Consolidation transactions where many inputs are merged into fewer outputs benefit from low or zero **storage mass** under KIP-9, because they reduce the UTXO set size. This makes consolidation relatively cheap compared to fan-out transactions that create many outputs.
</Callout>

### When to consolidate

- **Miners** should consolidate periodically, as they accumulate one UTXO per mined block
- **Payment receivers** who get many small payments should consolidate before making large sends
- **Before time-sensitive operations** where you need a single large UTXO ready for immediate use

### Multi-address HD wallet consolidation

The second function demonstrates consolidating UTXOs across multiple HD wallet addresses into the first address. When signing, pass all private keys to the `sign()` method so the SDK can match the correct key to each input.
