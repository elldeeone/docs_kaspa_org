## Prerequisites

- **Kaspa WASM SDK** installed (`npm install kaspa-wasm`)
- **Connection to a Kaspa node** with the UTXO index enabled (`--utxoindex`)

<Callout type="info">
Kaspa does not have "account balances" at the protocol level. A balance is computed by summing all unspent transaction outputs (UTXOs) belonging to an address. The node's UTXO index (`--utxoindex`) allows efficient lookup by address.
</Callout>

## Code

The following example demonstrates three approaches to querying balances:

```typescript
import {
  RpcClient,
  Resolver,
  Encoding,
  UtxoProcessor,
  UtxoContext,
  sompiToKaspaString,
} from "kaspa-wasm";

// Approach 1: Direct RPC query (simple, one-time check)
async function getBalanceSimple(address: string) {
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  // Query the balance directly from the node
  const result = await rpc.getBalanceByAddress({ address });
  const balanceSompi = result.balance;

  console.log("Address:", address);
  console.log("Balance:", sompiToKaspaString(balanceSompi), "KAS");
  console.log("Balance:", balanceSompi.toString(), "sompi");

  await rpc.disconnect();
  return balanceSompi;
}

// Approach 2: UTXO-based query (detailed, shows individual UTXOs)
async function getBalanceDetailed(address: string) {
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  // Query all UTXOs for the address
  const utxoResponse = await rpc.getUtxosByAddresses([address]);
  const entries = utxoResponse.entries;

  let totalBalance = 0n;
  console.log(`\nAddress: ${address}`);
  console.log(`UTXO count: ${entries.length}`);
  console.log("---");

  for (const entry of entries) {
    const amount = entry.amount;
    const isCoinbase = entry.isCoinbase;
    const blockDaaScore = entry.blockDaaScore;

    totalBalance += amount;
    console.log(
      `  ${sompiToKaspaString(amount)} KAS`,
      isCoinbase ? "(coinbase)" : "",
      `| DAA score: ${blockDaaScore}`
    );
  }

  console.log("---");
  console.log("Total:", sompiToKaspaString(totalBalance), "KAS");

  await rpc.disconnect();
  return { total: totalBalance, utxoCount: entries.length };
}

// Approach 3: Real-time balance tracking (continuous updates)
async function trackBalanceRealTime(addresses: string[]) {
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  const processor = new UtxoProcessor({ rpc, networkId: "mainnet" });
  const context = new UtxoContext({ processor });
  await processor.start();
  await context.trackAddresses(addresses);

  // Listen for balance changes
  processor.addEventListener("balance", () => {
    const balance = context.balance;
    console.log("\nBalance updated:");
    console.log("  Mature:", sompiToKaspaString(balance?.mature ?? 0n), "KAS");
    console.log("  Pending:", sompiToKaspaString(balance?.pending ?? 0n), "KAS");
    console.log("  Outgoing:", sompiToKaspaString(balance?.outgoing ?? 0n), "KAS");
  });

  console.log("Tracking balance for", addresses.length, "addresses...");
  console.log("Press Ctrl+C to stop.");

  // Keep the process alive
  await new Promise(() => {});
}

// Approach 4: Multiple addresses at once
async function getBalanceMultipleAddresses(addresses: string[]) {
  const rpc = new RpcClient({
    resolver: new Resolver(),
    encoding: Encoding.Borsh,
    networkId: "mainnet",
  });
  await rpc.connect();

  const balances = await rpc.getBalancesByAddresses({ addresses });

  let grandTotal = 0n;
  for (const entry of balances.entries) {
    const balance = entry.balance;
    grandTotal += balance;
    if (balance > 0n) {
      console.log(`${entry.address}: ${sompiToKaspaString(balance)} KAS`);
    }
  }

  console.log("\nTotal across all addresses:", sompiToKaspaString(grandTotal), "KAS");

  await rpc.disconnect();
  return grandTotal;
}

// Usage
const address = "kaspa:qr35ennsep3hxfe7lnz5ee7j5jgmkjswsn27efrq0";
getBalanceSimple(address).catch(console.error);
```

## Explanation

### Approach 1: getBalanceByAddress

The simplest method. The node sums all UTXOs for the given address and returns the total. This is a single RPC call and suitable for one-time balance checks.

### Approach 2: getUtxosByAddresses

Returns the full list of individual UTXOs for the address. This approach provides more detail:

- **UTXO count**: How many individual unspent outputs exist
- **Per-UTXO amounts**: The value of each output
- **Coinbase flag**: Whether the UTXO is from a mining reward (coinbase outputs have a maturity requirement)
- **DAA score**: When the UTXO was created, useful for determining maturity

### Approach 3: Real-time tracking with UtxoProcessor

The `UtxoProcessor` subscribes to node notifications and automatically tracks balance changes. The `balance` event fires whenever a tracked address receives or spends funds. The balance object contains:

| Field | Description |
|---|---|
| `mature` | Confirmed and spendable (coinbase UTXOs past maturity) |
| `pending` | Unconfirmed transactions or immature coinbase UTXOs |
| `outgoing` | Balance currently locked in outgoing unconfirmed transactions |

### Approach 4: Batch balance query

`getBalancesByAddresses` accepts an array of addresses and returns balances for all of them in a single RPC call. This is efficient when checking balances across multiple addresses in an HD wallet.

<Callout>
The UTXO index must be enabled on the node you connect to (`--utxoindex` flag). Public nodes accessed via the Resolver typically have this enabled. If you run your own node, ensure this flag is set or balance queries will fail.
</Callout>

### Converting sompi to KAS

All balances are returned in sompi (1 KAS = 100,000,000 sompi). Use `sompiToKaspaString()` for display and `kaspaToSompi()` when constructing transactions. The SDK uses `BigInt` for all amounts to avoid floating-point precision issues.
