## Overview

Kaspa's protocol work references academic research, but canonical proposal status lives in the KIPs repository and deployed behavior lives in `rusty-kaspa`.

This page focuses on papers that are directly cited in active/proposed KIPs. For authoritative bibliographic details (authors, publication date, revisions, venue), use the paper links themselves.
