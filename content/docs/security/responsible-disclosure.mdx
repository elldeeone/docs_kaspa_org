## Overview

Canonical reporting entry points for `rusty-kaspa` security issues are maintained on GitHub:

- [rusty-kaspa security page](https://github.com/kaspanet/rusty-kaspa/security)
- [rusty-kaspa security advisories](https://github.com/kaspanet/rusty-kaspa/security/advisories)

Because the disclosure workflow is hosted by GitHub, labels, forms, and step-by-step UI text can change. Follow the current instructions on those pages as the authoritative process.

## Scope

This page is limited to the canonical `kaspanet/rusty-kaspa` reporting entry points. Third-party wallets, pools, exchanges, and other ecosystem services maintain their own disclosure channels.

## Non-Security Issues

For non-security bugs and feature requests, use the public issue tracker:

- [rusty-kaspa issues](https://github.com/kaspanet/rusty-kaspa/issues)
