## Overview

Kaspa transactions are irreversible at the protocol level once confirmed on chain. This page intentionally stays within canonical scope and links to authoritative sources.

## Canonical Scope

The `rusty-kaspa` and `kips` repositories define protocol behavior and node implementation details. They do not define a single mandatory end-user operational-security policy.

Operational guidance such as seed backup procedures, anti-phishing checklists, device hygiene, and wallet-specific workflows is out of canonical protocol scope and should be taken from the official documentation of the wallet, service, or software you use.

## Canonical Sources

- [kaspanet organization on GitHub](https://github.com/kaspanet) — canonical project repositories and release artifacts.
- [KIPs repository](https://github.com/kaspanet/kips) — proposal and status metadata for protocol evolution.
- [rusty-kaspa repository](https://github.com/kaspanet/rusty-kaspa) — reference node implementation.
