## Overview

The Kaspa Web Wallet ([wallet.kaspa.org](https://wallet.kaspa.org)) is a client-side wallet that runs entirely in your browser. Your private keys are generated and stored locally — they are never transmitted to any server. The wallet communicates with the Kaspa network through public wRPC (WebSocket RPC) endpoints to broadcast transactions and query balances, but all cryptographic operations happen on your device.

<Callout>
The Web Wallet is non-custodial. If you lose your seed phrase, there is no way to recover your funds. No one — including the Kaspa developers — can reset your wallet or reverse transactions.
</Callout>

## Creating a Wallet

1. Navigate to [wallet.kaspa.org](https://wallet.kaspa.org) in a modern browser (Chrome, Firefox, Edge, or Brave).
2. Click **Create New Wallet**.
3. The wallet generates a **24-word mnemonic seed phrase** using the BIP-39 standard.
4. Write down the 24 words **on paper** in the exact order shown. Do not store them digitally (no screenshots, no cloud notes, no email).
5. Confirm your seed phrase by entering the requested words.
6. Set an optional encryption password. This password encrypts the wallet data in your browser's local storage. It does **not** replace your seed phrase — it only protects against someone accessing your wallet from the same browser session.

### Key Derivation

The Web Wallet uses **BIP-32 hierarchical deterministic (HD) key derivation**. From your single 24-word mnemonic, the wallet can derive a virtually unlimited number of key pairs. The derivation path follows the pattern:

```
m / purpose' / coin_type' / account' / change / address_index
```

For Kaspa, the coin type is `111111'`. This means all your addresses — receive and change — are deterministically generated from the same seed. As long as you have your 24 words, you can fully reconstruct your wallet and all its addresses on any compatible wallet application.

## Addresses

### Receive Addresses

Receive addresses are the addresses you share with others to receive KAS. The wallet generates new receive addresses as needed. You can always generate a fresh address for each incoming transaction to improve privacy, though reusing an address is not a security risk in Kaspa.

### Change Addresses

When you spend KAS, the wallet may need to consume an entire UTXO (Unspent Transaction Output) even if the UTXO's value is greater than the amount you intend to send. The excess value is sent back to your own wallet via a **change address**. Change addresses are derived from a separate branch of the HD derivation tree, but they belong to the same wallet and are fully controlled by your seed phrase.

<Callout type="info">
If you see a balance distributed across multiple addresses in your wallet, this is normal. The wallet automatically manages receive and change addresses behind the scenes.
</Callout>

## Sending KAS

1. Click **Send** in the wallet interface.
2. Enter the recipient's Kaspa address (a `kaspa:` prefixed address).
3. Enter the amount of KAS to send.
4. Review the transaction details, including the network fee.
5. Click **Confirm** to sign and broadcast the transaction.

The wallet will automatically select the appropriate UTXOs to fund the transaction. With Kaspa's 10 BPS block rate, your transaction will typically appear in a block within one second and reach full confirmation in approximately 10 seconds.

## Compound Transactions (UTXO Management)

Kaspa uses a UTXO model similar to Bitcoin. Each time you receive KAS, it creates a new UTXO. Over time — especially if you receive many small payments (e.g., from mining) — your wallet may accumulate hundreds or thousands of small UTXOs.

A single Kaspa transaction has a maximum size limit on the number of inputs it can include. If your balance is spread across more UTXOs than a single transaction can consume, the wallet cannot send your full balance in one transaction.

To solve this, the Web Wallet supports **compound transactions** (also called UTXO consolidation). This process:

1. Combines many small UTXOs into fewer, larger UTXOs.
2. Sends them back to your own wallet addresses.
3. May require multiple compounding rounds if you have a very large number of UTXOs.

<Callout type="info">
If the wallet shows a "Compound" button or prompts you to compound before sending, this means your UTXOs need consolidation. This is a normal operation and does not send funds to anyone else. The only cost is the standard network fee for each compounding transaction.
</Callout>

## Receiving KAS

1. Click **Receive** in the wallet interface.
2. Copy the displayed Kaspa address or use the QR code.
3. Share the address with the sender.

Each address is a Schnorr public key encoded in a Kaspa-specific Bech32 format, prefixed with `kaspa:`. For example:

```
kaspa:qr0emu7s4yrkunhp2p4vodqem59nnfmryzrsmjy7mvsrgf22ygqqxf7z8g5wv
```

## Security Best Practices

### Seed Phrase Protection

- Write your 24-word seed phrase on **physical media** (paper, metal backup plate) and store it in a secure location.
- **Never** enter your seed phrase into any website, application, or form other than the official Kaspa Web Wallet or a trusted compatible wallet.
- **Never** share your seed phrase with anyone. No Kaspa developer, support agent, or community member will ever ask for it.
- Consider creating multiple physical copies stored in different secure locations.

### Browser Security

Since the Web Wallet runs in your browser, your browser environment matters:

- Keep your browser updated to the latest version.
- Avoid browser extensions from untrusted sources — malicious extensions can read page content and intercept key material.
- Use the wallet in a clean browser profile or an incognito/private window if you are on a shared computer.
- Always verify you are on `wallet.kaspa.org` (check the URL and HTTPS certificate) before entering your seed phrase.
- Clear your browser data or log out of the wallet when you are finished, especially on shared machines.

<Callout>
For large holdings, consider using a [hardware wallet](/docs/wallets/hardware-wallets) or keeping funds in a wallet whose seed phrase has never been entered into a browser. The Web Wallet is convenient for everyday use, but a hardware wallet provides stronger key isolation.
</Callout>

### Transaction Verification

- Always double-check the recipient address before confirming a transaction. Kaspa transactions are irreversible.
- Compare the first and last several characters of the address to catch clipboard-hijacking malware.
