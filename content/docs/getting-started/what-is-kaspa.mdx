## Kaspa at a Glance

Kaspa is a proof-of-work cryptocurrency that replaces the traditional blockchain with a **BlockDAG** (Block Directed Acyclic Graph). Instead of a single chain where blocks are produced one at a time, Kaspa's DAG allows multiple blocks to be created in parallel and all of them to be included in the ledger. This architecture, combined with the [GHOSTDAG consensus protocol](/docs/core-concepts/ghostdag), supports the current **10 blocks per second** operating mode.

<Callout>
Kaspa is not a linear blockchain. It is a BlockDAG, where each block can reference multiple parents and consensus ordering is applied over a graph rather than a single chain.
</Callout>

## Key Differentiators

**BlockDAG architecture.** Kaspa includes parallel valid blocks in DAG ordering, which reduces the traditional stale/orphan loss seen in linear chains. This is fundamentally different from Bitcoin-style single-chain selection, where only one block per interval is retained in the canonical chain.

**GHOSTDAG consensus.** The GHOSTDAG protocol deterministically orders all blocks in the DAG, resolving double-spends and establishing a canonical transaction history. It is a direct generalization of Nakamoto consensus — a traditional blockchain is simply a special case of a BlockDAG with width one.

**10 blocks per second.** Following the Crescendo hardfork, Kaspa produces 10 blocks every second. First confirmations arrive in approximately 100 milliseconds, making Kaspa fast enough for point-of-sale and real-time payment use cases.

**Fair mining with parallel block inclusion.** Including parallel blocks reduces structural advantages from propagation races and tends toward more hashrate-proportional outcomes over long windows.

**Proof-of-work issuance.** KAS issuance follows consensus rules in node software, with emission behavior defined by protocol parameters.

## Protocol Evolution

Protocol changes are proposed and discussed through the [KIP (Kaspa Improvement Proposal)](/docs/protocol-evolution/kips-overview) process and activated through software upgrades. A key recent milestone is:

- **Crescendo hardfork** — Increased block production from 1 BPS to 10 BPS and updated related consensus parameters.

## The Vision

Kaspa's vision is to be **fast, fair, decentralized digital cash** — a peer-to-peer electronic payment system that is practical for everyday use. The project aims to prove that proof-of-work can scale to high throughput without resorting to proof-of-stake, federated validators, or centralized sequencers.

Core principles guiding Kaspa's development:

- **Decentralization first.** Anyone can run a node. Anyone can mine. There are no staking requirements, no validator sets, and no permissioned roles.
- **PoW sustainability.** The kHeavyHash mining algorithm is designed with future optical mining hardware in mind, potentially reducing the energy cost of proof-of-work by orders of magnitude.
- **Academic rigor.** Protocol changes are grounded in peer-reviewed research and formal analysis, not marketing timelines.

## Community-Driven Open Source

Kaspa is developed in the open. The primary node implementation, [rusty-kaspa](https://github.com/kaspanet/rusty-kaspa), is written in Rust and licensed under ISC. Contributions come from independent developers, researchers, and community members coordinating through public channels.

Protocol changes follow the [KIP (Kaspa Improvement Proposal)](/docs/protocol-evolution/kips-overview) process, which is open to anyone.

## Network Overview

At 10 BPS, the Kaspa network produces approximately **864,000 blocks per day**. The network is secured by a global pool of miners running the kHeavyHash proof-of-work algorithm. Key network characteristics include:

| Property | Value |
|---|---|
| Block rate | 10 BPS |
| First confirmation | ~100 ms |
| Consensus protocol | GHOSTDAG (k=124) |
| Mining algorithm | kHeavyHash |
| Maximum supply | ~28.7 billion KAS (effective emission; `maxSompi` is 29B KAS-equivalent) |
| Emission schedule | Chromatic (smooth monthly reductions) |

<Callout type="info">
Kaspa and Bitcoin share a proof-of-work foundation. The key difference is architectural: Kaspa uses a BlockDAG with GHOSTDAG ordering rather than a strictly linear chain.
</Callout>
