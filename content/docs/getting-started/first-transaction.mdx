This guide walks you through creating a wallet, receiving KAS, and sending a transaction using the **kaspa-wallet** command-line tool that ships with rusty-kaspa. Before proceeding, make sure your node is [running and fully synced](/docs/getting-started/quick-start).

## The Kaspa Wallet CLI

The `kaspa-wallet` binary is built alongside `kaspad` when you compile rusty-kaspa. It provides an interactive command-line interface for managing wallets, generating addresses, and sending transactions.

Start it by running:

```bash
./target/release/kaspa-wallet
```

This opens an interactive prompt where you can issue wallet commands.

<Callout type="info">
By default, wallet settings use `server=public` (resolver-backed public infrastructure). To force a local node, set `server 127.0.0.1:17110` and run `connect`. Ensure your node is running with `--utxoindex` so wallet/address-indexed queries are available.
</Callout>

## Creating a New Wallet

At the wallet prompt, create a new wallet:

```
wallet> wallet create
```

You will be prompted to set an encryption password and will be shown a mnemonic phrase (the current wizard defaults to **12 words**). This mnemonic is the sole backup of your wallet.

<Callout type="error">
Write down your mnemonic phrase immediately and store it securely offline. If you lose this phrase, your funds are permanently unrecoverable. Never share it with anyone, and never store it digitally in an unencrypted format.
</Callout>

After creation, the wallet automatically opens and is ready to use.

## Opening an Existing Wallet

If you have previously created a wallet, open it with:

```
wallet> wallet open
```

You will be prompted for the encryption password you set during creation.

## Connecting to Your Node

Once the wallet is open, connect it to your local node:

```
wallet> connect
```

The wallet will establish a wRPC connection to `kaspad` and begin syncing your UTXO set. You should see output confirming the connection:

```
Connected to 127.0.0.1:17110
Syncing UTXO entries...
Balance: 0.00000000 KAS
```

## Generating a Receive Address

Generate a new receive address:

```
wallet> address
```

This outputs a Kaspa address in the format:

```
kaspa:qr0e87surz8t2knkzegp0shs6nfhkdan0ka24grlftqfspem9v2wj2kfs8yz
```

Kaspa addresses start with the `kaspa:` prefix and use a Bech32-based encoding scheme. Each call to `address` derives a new address from your wallet's HD key path.

<Callout type="info">
Kaspa addresses are derived using BIP-32 hierarchical deterministic (HD) key derivation. You can generate as many addresses as needed -- they are all recoverable from your mnemonic phrase.
</Callout>

## Checking Your Balance

To see your wallet balance after receiving funds:

```
wallet> list
```

This queries the UTXO index on your connected node and displays both your mature (spendable) balance and any pending balance:

```
Balance: 152.47000000 KAS
  Mature: 152.47000000 KAS
  Pending: 0.00000000 KAS
```

## Sending KAS

To send KAS to another address, use the `send` command:

```
wallet> send kaspa:qpxz2rk7nqtf60stqa0ney8xsjxhgcpruxr69z6xyufge9a5cg4vk0yznw8x 10.5
```

This sends 10.5 KAS to the specified address and prints a summary with submitted transaction IDs:

```
Send - ...
Sending 10.5 KAS to kaspa:qpxz2rk7nqtf60stqa0ney8xsjxhgcpruxr69z6xyufge9a5cg4vk0yznw8x, tx ids:
...
```

<Callout type="info">
Kaspa transaction fees are calculated from transaction mass (size and script operations), not account-style gas. Fees are typically low in sompi terms; fiat cost varies with market price.
</Callout>

### Transaction Confirmation

At 10 BPS, inclusion is usually quick, but exact timing depends on network and node conditions. For higher assurance, rely on your own DAA-depth policy rather than a fixed wall-clock time.

You can verify the transaction was accepted by checking your balance:

```
wallet> list
```

Or by looking up the transaction ID on a Kaspa block explorer like [kas.fyi](https://kas.fyi).

## UTXO Consolidation (Sweep)

If your wallet has received many small UTXO entries (for example, from mining), you may need to consolidate them before sending larger amounts. The wallet handles this automatically when needed, and you can also trigger a manual sweep:

```
wallet> sweep
```

This consolidates small UTXOs into larger ones, making future transactions more efficient.

## Recovering a Wallet from Mnemonic

If you need to restore your wallet on a new machine or after data loss, use:

```
wallet> wallet import
```

You will be prompted to enter your mnemonic phrase and set a new encryption password. After import, connect to a synced node and the wallet will scan the UTXO set to recover your balance.

## Summary of Wallet Commands

| Command | Description |
| --- | --- |
| `wallet create` | Create a new wallet with a fresh mnemonic |
| `wallet open` | Open an existing wallet file |
| `connect` | Connect the wallet to a kaspad node |
| `address` | Generate a new receive address |
| `list` | List accounts and balances |
| `send <address> <amount>` | Send KAS to an address |
| `sweep` | Consolidate account UTXOs |
| `wallet import` | Recover a wallet from a mnemonic phrase |
| `export` | Display the current wallet's mnemonic |
| `wallet close` | Close the current wallet |
| `exit` | Exit the wallet CLI |
